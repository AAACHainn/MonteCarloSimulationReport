# PDF Chinese font

Noto Sans SC, SIL Open Font License 1.1 (see OFL-NotoSansSC.txt).

Source: https://github.com/google/fonts/tree/main/ofl/notosanssc

NotoSansSC-Regular.ttf is a static 400-weight instance of the official
NotoSansSC[wght].ttf, generated with fontTools.varLib.instancer.
The full source character set is retained for user-authored Chinese reviews.
Load this font only when creating PDF exports. No font service is contacted.
