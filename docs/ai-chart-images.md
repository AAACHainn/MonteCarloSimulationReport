# AI 图表图片工具

2026-10-16，按用户确认的方案，将新请求中的 `get_chart_context` 替换为 `get_chart_images`。行情读取、聚合与指标预热保留在程序内部；工具、固定资料模式与会话批次均不再向模型发送逐根 OHLCV 或 warmup 数组。精确交易事实、模板和统计工具继续保留。

## 使用与契约

默认获取当前回放图表及当前显示周期；单笔范围则默认该笔交易的原显示周期。明确要求多个周期时，可以一次取得最多 4 个周期的图片，例如“比较当前 5m、15m、1m 的图片”。没有列出具体周期但明确要求多周期时，模型可在本次合法周期中选择。

```json
{"chartRef":null,"timeframes":null,"cursor":null}
```

`chartRef=null` 使用当前图表或已选单笔；会话内其他交易须使用目录中的真实引用。`timeframes=null` 使用本次明确指定的周期，未指定时使用当前周期。多周期权限与明确周期列表固定在运行快照，不由工具调用自行扩大；非法周期与越权引用拒绝执行。

工具返回图片元数据、实际来源范围/时间、回放截止点、周期、时段、可见指标、来源回执与真实图片片段。没有 `bars`、逐柱 OHLCV、warmup 或独立数据模式。`includeImage` 和柱数 `limit` 已从新契约移除。

同一周期每个规范窗口最多 200 根柱，与 PDF 导出共用同一上限常量，窗口身份不随所请求的周期数量改变。长交易通过签名 `cursor` 继续读取后续图片；元数据标明覆盖范围。图表仍为冻结行情重建图，不含当前手动画线，不冒充历史原始截图。不同周期共享对应的固定截止点，不读取未揭示源 K 线。

## 交易标注、图例与编号

当前图表图片包含该窗口内、本次冻结截止点前已结束交易的自动标注；单笔图片只包含指定交易。标注事件映射到所属聚合柱，缺失源柱不补造标记。每张图的标注清单固定在上下文或变体内，预生成和浏览器按需生成共用该清单，不再用“当前图表”的虚拟 ID 筛选交易。

工具文字结果与图片一起发送：每图 `caption` 使用 PDF 渲染器的实际说明；`annotationLegend` 解释编号、委托缩写、方向、风险、退出标签和位置；`annotationMapping` 给出 `chartNo → displayNo / globalNo / journalAccount / tradeRef`；每图 `annotationNumbers` 指明纳入哪些交易。映射在多周期间去重，账户重号时为图片分配唯一编号，并保留原日志和内部编号。`chartRef` 是图表引用，不是图中交易编号。

`LMT/MKT/STP` 分别为限价/市价/止损入场委托，`B/S` 为做多/做空；颜色循环区分交易，不表示方向或盈亏。`iRisk` 位于已记录初始止损价；`aRisk` 是持仓结束后的最大不利变动对应价位，画在入场附近不表示当时已知或极值发生在该柱。`TP/SL/BE` 按该日志行未扣费价差结果生成，不能证明真实止盈/止损触发原因。标签文字为避让而移位，短虚线锚点才是事件价格。

沿用图表每图最多 100 笔自动标注的保护，超限保留最近记录，并明确返回 `annotationCoverage.truncated`、总数、已显示数和警告；不声称已显示全部标注。固定资料和会话图片批次也携带相同图例与映射。手动画线、手绘框、DOM 标签及尚未结束的持仓标注不在本次范围。

标注内容、编号映射和渲染版本参与图片身份，新版本不把旧的无标注 PNG 当作新图片复用。旧资产和原始记录保留；新工具可从旧冻结窗口重新生成带标注图片，不推进原截止点。未包含标注版本的旧批次图像标记为无法验证，不补造编号对应关系。

## 准备和按需生成

需求识别单独输出 `needsChartImages`、`multipleCharts`，图片准备不再仅由回答任务类型决定。已明确的窗口可在启动前预生成；普通讨论中随后调用图片工具，也可按需生成。

1. 服务端生成或复用固定窗口变体，核对行情/历史版本。
2. 在本次上下文中查找精确匹配的图片资产。
3. 缺图时创建持久截图任务，顶层浏览器管理器领取任务。
4. 浏览器复用公共离屏图表渲染器，生成真实 PNG 并上传。
5. 服务端校验任务、租约、运行状态和窗口身份；图片 READY 后继续模型请求。

任务复用 `AiRunStep` 的 `CAPTURE` 阶段，使用负 `stepNo`，不占模型调用次数。完整窗口保存在 `AiChartVariant`，不作为模型正文输出。无需数据库结构迁移。

同次工具调用的截图任务共享最多 90 秒的等待截止点，有 30 秒领取租约及定期续租；后续周期不会重新获得 90 秒等待，避免慢图耗尽整个工具时限并丢失先前成功的图片。刷新或断连后，可在租约到期后重新领取；已完成任务幂等确认。取消运行后拒绝迟到上传；过期、失败或没有可用浏览器时明确返回图片错误，不能退回 K 线数组或声称已看图。浏览器隐藏时不领取新任务；渲染遵守既有可见性等待。

已最小化但仍存活的页面可以处理任务；关闭标签页后不能生成新图。已上传图片仍可用于独立会话 worker。没有新增服务端浏览器或离线渲染依赖。

## 预算与错误

指标预热只考虑实际可见的 EMA，保留最多 1,000 根的上限。每张图片的读取预算独立计算，查询保护根据有界预热规模预留，源行预算仍为 25,000；多周期之间不会共享一份过小预算。图表读取错误为 `CHART_READ_BUDGET`，截图错误为 `CHART_CAPTURE_FAILED` / `CHART_CAPTURE_TIMEOUT`，与输出 Token 和工具调用上限区分。

继续保留每张图片 4 MiB、模型请求图片合计 12 MiB、每次工具最多 4 个周期、每次运行最多 100 个截图任务，以及模型请求和整次运行时限。图片工具整体等待最多 120 秒。部分周期失败时可保留其他成功图片，覆盖信息明确为部分完成。
