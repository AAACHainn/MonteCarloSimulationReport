# K 线多窗口回放首版设计

> 文档状态：设计与计划。适用范围：可交易回放页面的多周期工作区。实现后的使用规则见当前规范。
> 当前规范：[回放会话与纠错](replay-sessions-implementation.md)、[会话绘图持久化](../charting/archived-drawings.md)、[桌面 UI 规范](../ui/ui-guidelines.md)。

## 范围

在同一行情数据集、同一回放会话内，同时观察最多五个周期图。工作区只有一套播放控制、一个回放进度和一个交易账户。窗口 1 是主窗，手动「下一根」及其快捷键固定按主窗显示周期推进。图上交易交互由主窗提供，副窗用于观察行情、订单、持仓和成交，也能独立绘图。

入口仅添加到可交易的回放页面。历史只读页保持单图，读取同一会话的主窗绘图。本期同步回放进度与交易状态，十字线联动、时间范围联动和多窗拼图导出留待后续讨论。

## 布局与窗口身份

| 窗口数 | 首版模板 |
| --- | --- |
| 1 | 当前单图 |
| 2 | 左右、上下 |
| 3 | 左一右二、上一下二 |
| 4 | 2×2、左一右三 |
| 5 | 上一下四、左一右四（右侧 2×2） |

- 在现有图表工具栏添加「布局」入口。布局菜单用缩略图和简短名称，例如「左一右四」，支持鼠标和键盘选择，视觉样式沿用系统主题。
- 窗口内部编号固定为 1～5。模板中的第一个位置放主窗，其余按模板阅读顺序排列。图表标题显示品种和周期，界面隐藏内部编号。切换模板时，周期、显隐、指标和绘图跟随编号。缩减窗数只隐藏多余窗口，恢复时读回其设置及绘图。切回单窗始终显示窗口 1。
- 分割线调整相邻区域的宽高，支持拖拽和键盘方向键，约束最小尺寸。每种模板独立记住比例，「重置布局比例」恢复当前模板的默认比例。空间无法满足模板最小尺寸时临时显示主窗，空间恢复后恢复选定模板。临时切换保留已保存的模板和比例。

## 激活与单窗最大化

- 点击某张图或通过键盘选择其图表区域即激活。用当前主题的强调色描边，公共工具栏同步呈现激活图的周期和图表控制状态。绘图工具、对象列表、显隐和指标设置作用于打开控件时的目标窗。切换激活窗口本身只改变操作目标。
- 图内普通点击继续执行该图的正常交互。布局切换隐藏了激活窗口时，焦点回到主窗。每窗独立缩放、平移、重置视图和跟随最新行情，手动移开后沿用现有跟随规则。
- 在图表绘图区按 `Alt + 左键`，激活并最大化该图，再按一次恢复原布局、比例以及原有视口位置和跟随状态。提供键盘可达的「最大化图表／恢复布局」按钮。最大化发生在图表工作区内，现有网页全屏仍是单独入口。最大化期间保留公共播放控制，副窗最大化时保持副窗的交易观察模式。
- 处理最大化手势时，阻止同一点击触发绘图、测量、选中订单或拖单。分割线、表单和弹窗继续由各自控件处理。切换布局和最大化须保护正在编辑或保存的绘图，沿用既有的编辑收尾、保存与失败反馈。

## 行情、播放与交易

- 所有图使用同一份源 K 线和同一个会话已确认的源序号。各窗按自己的周期和共享的交易时段（ETH／RTH）聚合，只读取和渲染已揭示范围。高周期的形成柱随已揭示的源行情更新。缺失源 K 线沿用现有处理，显示周期继续遵守[源周期与显示周期约束](../market-data/time-aggregation.md#存储层级与显示周期)。
- 现有回放引擎统一处理播放、暂停、速度、步进、定位、撮合和会话保存。主窗继续使用原有周期切换与自动播放规则。改变副窗周期、切换激活图、拖动分割线或最大化只改变视图。例：主窗 5 分钟、副窗 1 小时，在副窗激活或最大化时按「下一根」，仍以主窗 5 分钟柱为目标，小时图更新到同一已揭示位置。
- 订单、持仓和成交来自同一份交易状态。各窗按实际源时间和源序号映射到自己的聚合柱，标记显示与否由本窗设置控制。右键下单、编辑或拖动订单线、操作持仓按钮及交易草稿等图上入口仅在主窗可用。公共交易面板继续服务同一个账户。
- 通过交易日志进入可交易页内的回看模式时，临时显示主窗并沿用现有回看与交易限制。返回当前回放后恢复先前布局。临时回看期间保留副窗设置与已保存绘图。
- 复用现有有界窗口读取、聚合和指标预热机制。相同查询范围可复用结果，副窗只读取其视图所需的已揭示行情。副窗请求失败时在对应区域提示和重试，主窗及其他图可以继续使用。切换会话、结果投影、时段、周期或回放位置后，旧响应须与当前请求上下文核对，避免回填不适用的旧行情。

## 配置与绘图保存

| 保存内容 | 首版规则 |
| --- | --- |
| 布局模板和分割比例 | 保存到当前浏览器。激活状态和单窗最大化属于临时状态，重新进入时从主窗激活。 |
| 显示周期 | 主窗沿用当前会话的周期保存规则。副窗周期按浏览器、数据集和窗口保存。首次打开优先从已有快捷周期中按从小到大选取合法且尚未使用的周期，数量不足时沿用主窗周期。保存值不再合法时按同一规则补齐。 |
| 图表显示设置 | 按浏览器和窗口保存指标及参数、显隐、图表样式。主窗接续已有偏好。副窗首次使用图表默认配置，保存后独立恢复。ETH／RTH 和显示时区沿用工作区共用设置。 |
| 绘图对象 | 继续保存在数据库。沿用现有数据集和回放会话作用域，新增固定窗口编号。旧绘图归入窗口 1，新增窗口初次为空。归档保留所有窗口的绘图，历史只读页只展现窗口 1。新建会话按既有规则从空绘图开始。 |

- 绘图归属与显示周期无关。切换窗口 2 的周期后，已存在的绘图继续归属于窗口 2，由现有锚点规则投影到新周期。隐藏窗口或改变布局只影响可见性。
- 复用现有绘图模板和快捷键定义。选择、对象列表、清空、对象复制粘贴、撤销重做及待确认保存按窗口隔离。切换激活图或暂时隐藏窗口后，已有写请求仍归原窗口。保留现有的会话和结果投影校验、幂等重试、并发冲突和失败恢复。 [绘图编辑与并发规则](../charting/drawing-editing.md)
- 建议给 `MarketDrawing` 增加取值为 1～5 的窗口字段，默认 1。查询、新建、更新、删除、清空、撤销恢复和幂等校验均须验证此作用域。现有单图调用省略该字段时按窗口 1 处理，历史页面的默认列表和清空也只作用于窗口 1。
- 若采用上述数据库变更，按[升级指南](../operations/upgrade.md#数据库版本基线与升级边界2026-10-27)同步 schema、增量迁移、新安装与升级入口。开工先核对统一升级入口实际状态，在隔离测试库和副本验证支持的 v1.0 来源与绘图保留，正式库升级另行安排。
- AI 取图及 PDF 导出继续以单图为渲染单位，需要使用当前工作区图表上下文时取主窗。显式选定的周期及已有冻结任务沿用各自契约。 [AI 图片契约](../ai/ai-chart-images.md) · [PDF 导出规则](replay-pdf-export.md)

## 首版验收

1. 已有会话升级后打开单窗，旧绘图的内容、ID、样式、所属会话和顺序保持。历史页仍能读取和编辑主窗绘图。全新安装也能直接使用。
2. 分别打开 1～5 窗及所有模板。切窗数、拖动分割线、重置比例、刷新、最大化并恢复后，窗口 ID、设置、已保存绘图和跟随状态符合本设计。测试焦点、键盘操作及绘图手势冲突。
3. 在主窗 5 分钟、副窗 15 分钟和 1 小时的组合下，分别测试点击、快捷键和自动播放。副窗激活或最大化时，步进与单窗一致。高周期形成柱、缺失行情、时段切换和加载失败均遵守同一已揭示边界。对相同交易操作，单窗与多窗的成交、进度和账户结果一致。
4. 分别在两窗创建绘图、选择同周期、清空或撤销其中一窗，验证其他窗保持独立。覆盖隐藏后恢复、换浏览器读取已保存绘图、切换会话、旧请求晚到及跨窗写入被拒绝。
5. 副窗订单、持仓和成交按本窗周期正确显示，显隐独立。图上交易写操作只在主窗触发，保证同一次交易只有一条命令。检查交易关卡、右侧交易面板、网页全屏、日志回看入口及返回主回放后的布局恢复。
6. 在浅色与暗色的 1280 / 1440 / 1920 px 桌面工作区检查图表最小尺寸、布局菜单、激活描边和分割线，并验证低高度和侧栏展开。五窗播放时检查推进调用、历史查询和渲染开销，以及缩减布局后非可见图表的请求和事件订阅。
