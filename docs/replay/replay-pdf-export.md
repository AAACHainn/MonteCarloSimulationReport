# 回放交易 PDF 导出

在回放交易历史中应用筛选，点击“导出 PDF”，从下拉框选择统一周期和 ETH/RTH；不提供自定义周期输入。
自营账户的导出范围跟随表格当前查看的轮次：查看某一轮时仅导出该轮，查看全部轮次时导出全部轮次，并应用表格已生效的筛选条件；分页不限制导出条数。任务开始后固定轮次与筛选条件，重试或切换页面不会改变该任务的范围。
ES 等支持时段的品种默认 RTH。若开平仓时间不属于所选时段，导出会提示交易编号，
请切换时段或调整筛选后重新开始。

明细页可关闭；开启时 No 固定保留，其余字段单独勾选并记忆，与表格显示列无关。
周期、时段、已生效筛选及浏览器图表偏好在开始时固定。
RTH 截图复用回放的 Bar Count 设置（开关、标注间隔、最近交易日数及颜色），
同时遵循回放的指标总开关和不超过 1H 的周期限制。
最近交易日数相对于每张截图的最后一个交易日计算；编号从交易时段开盘起算，不从截图左端重新编号。
图中只标注本次入选交易；统计根据完整筛选快照计算，不因分图重复累计。

截图按实际聚合 K 线计数，每图最多 200 根、6 条记录。
长持仓分图重叠 20 根。默认开仓前 50 根、平仓后 20 根，交易跨度较大或数据不足时缩减上下文。
交易原始指标不会按截图周期重新计算。

每卷最多 50 张图，完成后点击“下载并继续”，当前卷下载后才生成下一卷。
切换应用内页面不会停止任务；切到后台暂停截图，返回后继续。
关闭状态面板或取消会结束任务；刷新/关闭浏览器不能恢复。
普通错误可重试当前卷；行情版本冲突需重新开始。已下载的卷可以保留。

## 验证

新增 Vitest 测试覆盖筛选快照、窗口只读及版本冲突、RTH 夏令时、
块级汇总读取、200 根分图、续图覆盖、100 张图规划与字段配置。

生产构建中需检查 Web Worker 分块、中文字体和 PNG 嵌入。
浏览器验证包括桌面/窄屏弹窗、字段记忆、应用内导航、取消/重试和分卷下载。
下载后使用 PDF 文本提取与页面渲染检查中文、选中字段、长复盘换行和截图标记。

中文字体未覆盖的字符（如部分 emoji）以 Unicode 码点显示，避免截断后续复盘文字。
