# 会话绘图持久化

## 使用规则

- 归档保留原会话绘图，不清空、不复制。新会话绘图为空，各会话互相隔离。
- 普通回放和所有历史复盘页统一读取后端；新建、移动、缩放、设置矩形样式和删除通过会话接口保存。刷新或换浏览器以后仍以同一份后端数据为准。
- 归档后的成交、账户、进度和撮合仍只读；绘图编辑不会增加交易命令、推进进度或改变会话状态。
- 已归档与正在进行中的会话使用相同的绘图保存流程。同一会话的普通回放和历史页共用后端绘图，不再保留本地或页面内存中的独立草稿模式。
- 对象窗口新增“清空”。它只删除点击时列表中的本会话对象，不删除其他会话或随后由其他页面新建的对象。删除与清空直接执行，失败恢复对象并显示错误。
- 拖动期间只更新前端预览，松开后提交；选择、取消和几何未变化不写库。历史页绘图请求串行，处理中阻止重复提交。

## 浏览器草稿

已删除历史绘图的 localStorage 读写、存储键与草稿解析代码，所有历史页都忽略已有浏览器草稿，不读取、不合并，也没有迁移、导入或备份提示。此前仅在浏览器中的新增和修改不再生效；此前仅在浏览器删除、但后端仍存在的对象，需要重新删除一次。样式模板和图表偏好仍按原规则保存在浏览器。

## 实现与升级

- 复用 `MarketDrawing.replaySessionId` 及现有索引，无数据库结构变更，不需要新增 Prisma 迁移或初始化数据库。
- 绘图接口单独使用归档绘图写入校验，仍要求正确会话与 `X-Replay-Projection`。事务内再次校验会话版本、所属结果与纠错锁；普通交易接口继续沿用原只读限制。
- 单个删除、批量清空和 PATCH 均限定行情与回放会话，避免同一行情下跨会话修改；常规单个对象保存不重新传输全量绘图。
- 安装和运行更新遵循[升级指南](upgrade.md)。生产运行需重新构建、重启并刷新浏览器；不重置数据库，不自动导入或清理任何现有归档。

## 历史绘图样式设置

历史页的趋势线、斐波那契和矩形都可从对象窗口的设置按钮打开样式弹窗，也支持双击对象名称或图表绘图。趋势线和斐波那契与普通回放复用 `LineSettingsDialog`，支持原有颜色、透明度、线宽、线型、端点价格标签、回撤层级和模板功能。

调整只更新图表预览，确认时保存一次后端；取消保留原样式。保存成功后才更新下一次绘图的默认样式；失败保留弹窗与草稿并显示错误。保存期间禁止重复提交和关闭。矩形继续复用原有设置组件；账户、成交和回放进度仍只读。

本次相关 6 个测试文件、100 项通过，TypeScript、Lint、隔离生产构建和差异检查通过。浏览器验证历史页设置按钮、双击对象名称、取消恢复、保存后刷新保留、重复回撤层级校验、模板保存/跨页选用/删除，以及普通回放共用弹窗保存。375 / 1280 / 1440 / 1920 px 布局检查通过，无新增 UI 规范例外；测试前后 12 个交易相关表内容摘要一致，未重启业务服务。
