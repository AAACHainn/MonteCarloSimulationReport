# AI 助手自动交互：历史实施摘要

2026-10-16，按当时确认的方案取消每次提问前的角色选择，改为一个机器人自动关联当前页面资料。本文记录流程边界和当时验证范围；当前行为与限制以 [AI 机器人说明](ai-assistant.md) 和 [图表图片工具](ai-chart-images.md) 为准。下述验证是历史记录，并未在本次文档整理中重跑。

## 流程边界

- 页面 Provider 注册当前会话、可见图表或正在编辑的单笔交易；单笔编辑上下文优先于页面会话。卸载时按所有者清理注册，避免旧页面覆盖新范围。
- 自动分派只输出经过 schema 校验的任务类型、目标和明确选项，不接受模型提供的任意会话 ID、SQL 或路径。服务端在唯一明确的会话/projection 中解析交易编号；缺对象、编号歧义或模板不明时请求澄清，不猜测全库记录。
- 运行使用冻结的事实、图表偏好和时间截止点。图表只包含已揭示行情；固定历史资料不会因后续提问推进截止点。缺图可由在线浏览器按需生成，等待有界，失败时明确报告。
- 草稿需通过来源、原文和版本冲突检查后才能采用到编辑器；采用不会自动保存业务记录。取消、准备失败或校验失败不覆盖现有内容。
- 自动分派最多发起一次模型请求，不自动重试或切换端点。准备凭据有时效并绑定问题与范围；显式重试沿原决策继续，预算与用量记录遵循固定运行配置。

## 当时验证范围

使用隔离 SQLite 样本、本地模拟模型和浏览器，覆盖自动定位交易、工具读取、会话总结及普通追问、资料歧义、模板和实时草稿、采用但不保存、准备取消、同对象历史、固定图表截止点、刷新恢复和下一条输入保留。检查了 375/1280/1440/1920px 窗口、菜单键盘行为与焦点返回；当时记录为 808 项通过、2 项原有跳过，以及 lint、TypeScript、生产构建通过。未调用真实模型供应商，因此这些结果不证明供应商质量、兼容性或费用。
