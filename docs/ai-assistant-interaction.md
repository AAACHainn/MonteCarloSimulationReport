# AI 助手自动交互实施说明

2026-10-16，按用户确认的方案在 `ai-dev` 取消每次提问前的角色选择，并重新组织助手窗口。此前 Function Calling A—C 的五个工具和业务校验继续使用，D 阶段及跨会话、知识库、写入工具未扩展。本次不修改数据库结构，不需要新增迁移。

## 请求流程

1. 回放会话 Provider 注册当前会话；图表报告可见源序号、周期和时段；复盘编辑器注册单笔身份、模板与实时未保存草稿，优先级高于页面会话。注册在卸载时按所有者清理，避免旧页面覆盖新页面。
2. 发送后，`assistant-plan` 只向当前模型提供问题、有限的同对象历史和精简对象身份。模型输出经过 Zod 校验的内部任务、目标类型、交易显示编号、明确周期及模板/全图需求，不接收任意会话 ID、SQL 或路径。
3. 服务端在唯一明确的会话/projection 内解析目标，按实际日志显示编号定位，不猜测全库最近一笔。编号不存在或有歧义、没有对象、模板无法唯一确定时提示补充，保留输入；普通知识问答可以没有业务资料。
4. 固定快照及图表偏好，按需准备已明确要求的图片，再创建运行。模型在快照内自行调用五个只读工具；整个会话报告仍由程序覆盖全部批次，普通追问使用有限工具循环。
5. 草稿通过原有结构、已读来源和原文冲突校验后可采用到编辑器，正式保存仍由用户完成。取消、准备失败及未通过校验不会覆盖业务记录。

`globalAssistant / chartReading / reviewDraft / sessionReview` 保留为内部流程与高级配置，不再是聊天中的手动角色。生成正文和讨论交易分开判断；报告后的追问不会仅因历史任务类型而重跑报告。

## 范围和证据

默认关联当前页面。手动指定其他资料时固定该范围，在本机按聊天记忆；无页面对象时可沿用该聊天上次的资料。新聊天无对象则等待明确身份。查看历史消息来源只查看，不隐式替换下一次资料；需要时可明确选择沿用。

当前图表只使用可见且已揭示的窗口，服务端将右端限制在真实回放进度内；每页所有周期合计最多 80 根。平移历史会更新下一次提问的指针，已开始运行不变。重建图不含手动画线、DOM 标签，也不冒充原始历史截图。

自动关联的快速会话可按需读取其中交易的图表数据：固定交易、版本、平仓截止点和每周期最多 50 根背景的规划规则，实际读取前后核对数据/历史版本，再存为具体变体。快速问答不会因此成为逐笔全图报告。模型临时要求而没有准备的图片仍明确缺图，不等待离线浏览器。固定历史资料的追问不会因为要求另一周期而自动推进旧截止点。

新快照中的同对象历史可用于承接讨论，但只作为历史参考，不替代当前事实。不同会话、projection 或单笔范围不重放业务正文。编号与日志显示使用同一编号函数，纠错后的存储编号空洞不改变“第 N 笔”的含义。

## 预算、记录和失败

自动分派每次最多一次模型请求，沿用全局端点和配置的单次时限（默认 120 秒），不自动重试或切换服务。成功创建运行后，其真实决策、请求摘要、耗时及用量保存在 `AiRunStep` 的 `ROUTING` 阶段，计入累计输入和配置的调用上限：普通工具请求默认总计最多 6 次，整个会话默认最多 750 次。执行模型请求数仍在 `calls`，API 的 `totalCalls` 包含本次分派；显式重试沿用原决策，不重复计入原分派费用。

后续用量需求加入全局上限与聊天临时调整，见[使用说明](ai-assistant.md#限制存储和部署)。每次准备和运行固定有效配置；聊天累计 Token、最近输出/上限、字符与请求保护分别呈现，缺失用量保留未知。临时设置刷新后恢复全局值；调整后重试沿原快照，会话继续保留批次与累计计数。

准备凭据仅保留有界、10 分钟有效的服务端临时记录，绑定聊天、问题摘要、任务与上下文；凭据过期或服务重启后提示重新发送，不自动再次计费。澄清、准备取消、分派失败不创建运行，可能已经发生一次模型请求；不将该状态伪装成成功分析。图片复用同一上下文已保存的有效资产。

准备中禁用聊天切换和重复发送；输入区仍可编辑下一条问题，完成或停止不会清除后来输入的文字。聊天初次读取完成后才开放输入，避免异步恢复历史时丢失输入。

## 窗口设计与验证

沿用浅色、蓝色操作与 Slate 层级。顶部保留聊天、创建和历史，重命名、清空、删除及兼容选项进入低频菜单；中间以对话为主；底部集中显示资料范围、输入和唯一发送操作。快捷示例只填写问题，不隐藏发送。兼容设置与来源详情进入独立弹窗，减少长期占据输入区的控件。复用 `Dialog`、`Button`、`Textarea` 和 `OptionPopoverContent`，菜单交互沉淀为 `ActionMenu`；固定文案集中到 `copy`。

新增 10 项隔离集成测试覆盖实时/空草稿、所选模板、采用不保存、交易编号与歧义、无对象澄清、纯知识问答、旧 projection、决策异常、图表未来哨兵、可见窗口、固定截止点、同对象历史、分派凭据/用量/重试及共享预算收束。

使用全新隔离 SQLite 样本和本地模拟模型，浏览器跑通自动定位第 3 笔、工具读取、整个会话报告与普通追问、切换会话、空会话当前图表配图、无对象澄清、模板与实时草稿、采用不保存、准备取消及下一条输入保留。检查 375/1280/1440/1920px 的窗口与输入可见性、菜单 Escape 及焦点返回、重命名弹窗焦点，未发现页面错误。未调用配置中的真实供应商；模型实际识别质量与费用仍需真实使用验证。

本次没有 UI 规范例外；浮动工作窗使用规范允许的可移动、可调整尺寸布局。最终全量回归 808 项通过、2 项原有跳过；lint、TypeScript、生产构建、文档相对链接与 `git diff --check` 通过。以最终生产构建再次验证上述四种宽度、真实 API/worker/工具链、来源查看不切换范围、明确沿用资料、刷新后的范围记忆与切回当前页面，以及草稿采用和取消，均通过。真实模型质量不由本地模拟响应证明。
