# AI 机器人与交易复盘

本版本提供一个全局机器人，支持模型配置、回放历史交易的单笔复盘，以及单个回放会话的归纳。右下角机器人图标、历史日志中的“交给 AI”“总结本会话”均打开同一窗口。

## 配置与启动

已有安装先按[升级指南](upgrade.md)备份，并沿用原有数据库管理方式：

- Prisma 管理的安装应用迁移 `20261015180000_add_ai_assistant`。
- 使用 SQLite 初始化入口的旧安装在副本演练后运行 `corepack pnpm run db:init-sqlite`，不要混用迁移命令绕过历史问题。

为本地服务配置一次独立的 AI 加密主密钥：

~~~powershell
node scripts/setup-ai-key.mjs
~~~

脚本将随机主密钥写入被 Git 忽略的本地 `.env`，不输出密钥。已有有效配置保持原样，无效配置报错并保留；重启服务后生效。它不替换原行情加密主密钥。

其他部署可以在服务环境配置稳定的 `AI_ENCRYPTION_KEY`（32 字节、标准 Base64）；Compose 已提供映射。数据库、对应存储文件与原主密钥须一起备份，不要在另一台机器上重新生成主密钥后直接读取原密文。

进入“AI 配置 → 大模型”，添加端点名称、Base URL、默认模型 ID 和可选 API Key，选择启用的端点。可拉取模型或手动添加。Base URL 应包含服务商所需版本路径，界面预览最终地址；高级选项允许完整请求地址，并可选择 `max_tokens` 或 `max_completion_tokens`。

当前适配 OpenAI-compatible Chat Completions。保存、打开设置和切换模型均不自动探测；文本、图片、工具和结构化输出由用户分别点击测试，可能收费。不会自动重试付费请求或切换供应商。

已保存密钥只返回状态，留空保留、显式勾选才清除。“眼睛”仅显示本次新输入。端点地址、密钥或协议参数改变后相关测试状态失效。技能页可编辑提示词、启停、选择明确的端点/模型覆盖，并经确认恢复默认；任务提示词不能解除服务端边界。

## 单笔复盘

历史日志中双击复盘单元格，选择模板并编辑原文后点击“交给 AI”。系统固定模板、未保存原文、交易事实与图表；也可从机器人“选择参考资料”指定会话、单笔交易和模板。未选择模板时明确使用自由格式。

输入例如“按模板完善复盘，保留我的观点，没有记录的原计划和情绪不要编造”。通过长度及来源校验后，可点击“采用到复盘编辑器”；采用只更新编辑草稿，仍需核对并点击原编辑器的“保存复盘”。

- 正文保留 2,000 个 Unicode 字符，详细分析及证据另存于聊天、运行和固定资料中。
- 原文、会话或交易结果改变时提示冲突；不静默覆盖。
- 保存人工与 AI 辅助来源，AI 辅助文字不作为独立成交证据。
- 生成、失败或停止不改变成交、订单、Setup、交易理由或检查快照。
- 普通文本或未通过结构/来源校验的回答可以阅读，但不能直接采用。

## 单会话分析

“总结本会话”覆盖该会话当前有效结果内的全部已结束日志，包含没有复盘的记录，不受表格分页影响。

| 模式 | 输入与用途 |
| --- | --- |
| 快速：文字与统计 | 交易、笔记、检查快照与程序指标；明确未审阅全部图表。 |
| 完整：逐笔图表 | 逐笔准备图表，分批阅读后汇总；长持仓可能分成多张图。 |

发送前显示范围、复盘覆盖率、预计至少需要的调用和图片数量。价格和真实用量无法确定时费用保持未知。

分析使用独立 Node 子进程，保存批次和分层汇总检查点。关闭窗口不会取消后台分析，“停止”会取消。中断或运行时限到达后可显式继续，沿用原资料和模型；状态不明的付费步骤可能再次计费。

报告从“已保存会话报告”查看；复盘、进度或纠错结果改变后保留旧证据并标注变化。删除聊天不删除正式复盘或已保存报告。候选规则附支持、反例及验证动作，不自动写入原策略。

## 证据与统计口径

- 总体统计复用完整持仓交易 `PaperTrade`，净盈亏为 `grossPnl - fees`，滑点已在成交价中体现，不重复扣除。
- FIFO 行数与完整持仓交易数分别显示；分组价差明确为未扣费行口径，不宣称已可靠分摊手续费。
- 风险缺失时不补造 R 分母；未结束交易不混入已结束交易胜率。
- 成交和已记录订单操作按当前 projection、持仓周期和源序号关联；旧资料无法可靠关联时说明缺口。
- 消息显示实际模型及参考时点。模板、原文、检查快照、交易与图表固定到发送快照，切页不改变运行对象。
- 图表复用源周期聚合与块级摘要，默认截至平仓；形成中的高周期柱不读未来源 K 线。
- 重建图不是原始入场截图，不能恢复逐笔路径。当前手动画线和 DOM 标签未并入图，EMA 使用截图窗口，不能声称全历史递推。
- 图片能力未验证时提示先测试或移除图片；上传图片单列为用户参考资料，不自动证明拍摄时点和交易归属。

本版使用服务端准备的固定上下文，没有开放模型自主查询全库的工具循环。工具测试独立验证协议能力，不表示普通回答已调用工具检索。Embedding、知识库、跨会话研究及训练即时辅导尚未接入。

## 限制、存储和部署

限制见 `lib/ai/schema.ts`：单个范围最多 5,000 条日志、100 张重建图；手动图片一次最多 6 张、每张 4 MiB。输入按字符及图片预算估算，并非供应商的真实 Token 容量承诺。

模型单次超时 120 秒，一段运行 300 秒。分析最多 750 次调用、累计输入估算 5,000,000 字符；大范围会先检查预算，超限不静默删记录。运行时限可显式继续，累计预算用尽则需缩小范围。

AI 表、复盘来源与报告保存于 SQLite，图片位于 `storage/ai/`。完整备份包括数据库、图片和主密钥；独立交易日志 ZIP 不包含回放 AI 报告。当前不自动批量清理证据或图片。

Dockerfile 已补充 worker 所需 `scripts/`、`lib/` 与 `tsconfig.json`，需发布包含当前代码的镜像。本地 worker 与主应用沿用同一数据库和环境。
