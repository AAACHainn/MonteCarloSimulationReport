# 矩形绘图与性能验证

> 文档状态：当前规范。适用范围：矩形绘图的使用与实现约束；性能数字与验证结果仅代表 2026-10-19 的记录。

2026-10-19。本功能复用已有绘图存储和时间轴定位器，无新增依赖、数据库结构迁移或行情接口。

## 使用

- `Shift + R`（Windows / Mac 通用），或“绘图工具 → 矩形”；两次点击确定对角。时间吸附显示 K 线、价格吸附最小跳动，零宽或零高不提交；完成后退出绘图模式，Escape 取消。
- 默认沿用绘图蓝色、不透明度 15%、无边框。填充颜色、不透明度 0～100%、边框颜色、1～4 px 线宽与实线/虚线/点线可单独配置。完全透明且无边框的样式不允许保存。
- 无边框也可点击几何边缘选中；未选中的内部保留图表操作。选中后有 8 个控制点，可拖动内部移动、拖动控制点缩放。订单价格线和测量手势优先，其他线条优先于选中矩形内部。
- 选中提示属于编辑层，不计入保存样式。填充在蜡烛下方，边框和控制点在上方；矩形不参与价格轴自动缩放。
- 双击边缘或通过对象窗口的设置按钮编辑。点击删除按钮或选中后按 Delete / Backspace 直接删除，无需确认；保存或删除失败时恢复原对象。设置和模板控件支持键盘、焦点及输入校验。
- 保存、应用、覆盖同名和删除模板；每类最多 50 个、名称最多 50 字符，只保存样式，不保存几何。覆盖同名模板需要确认，删除模板直接生效，已有矩形不受影响。模板仅在矩形设置中管理，绘图工具菜单只保留工具入口；设置确认成功后更新下一次默认样式。
- 矩形、趋势线和斐波那契设置共用样式控件。矩形弹窗沿用趋势线的紧凑布局、颜色选择与色值、透明度滑杆、边框线型和线宽按钮；底部“保存模板”打开独立名称弹窗，不在样式表单常驻名称输入。
- 模板和默认样式保存在当前浏览器、当前站点的 localStorage。普通回放和所有历史页的绘图均经会话 API 保存到后端，同一会话共用绘图，刷新后保留。所有历史页均已移除绘图草稿的浏览器存储逻辑，忽略旧草稿。详见[归档绘图持久化](archived-drawings.md)。

## 实现与性能约束

- [数据与校验](../../lib/market-replay/chart-drawings.ts)：新增 `RECTANGLE`，使用两个时间/源序号/价格锚点和独立样式。已有 SQLite `type` / JSON 字符串字段继续适用，PATCH 同时校验类型匹配和退化几何。
- [矩形 primitive](../../lib/market-replay/rectangle-primitive.ts)：一个实例管理全部矩形，使用共享 `DrawingTimelineLocator`，两个 Canvas pane view 分别负责填充和编辑层。裁剪不改保存数据，保留包围整个视口但四角均在屏外的矩形。
- [图表交互](../../components/market-replay/replay-chart.tsx)：按绘图数组变化分组，复用共享索引和缓存；鼠标事件每帧处理最新一次，绘图同步继续合并。移动仅更新 ref 预览，松开提交一次；只选择、取消或几何未变化不提交。只调整价格边缘保留原时间/源序号，只调整时间边缘保留原价格，避免高周期下改写未编辑的锚点。
- [共享设置和模板](../../components/market-replay/rectangle-controls.tsx) 同时用于普通和历史页；[共用样式控件](../../components/ui/style-controls.tsx) 统一各类绘图表单。UUID 使用统一 `createUuid()`，支持普通 HTTP。

### 浏览器

使用全新隔离数据库和生产构建，经局域网 IP 的普通 HTTP 访问，确认 `isSecureContext=false`、`crypto.randomUUID` 不可用，新建矩形和模板成功。初版验证两次点击绘制、Alt + R、控制点拖动、颜色/不透明度/虚线边框、模板跨普通/历史页复用、刷新保留、删除确认取消、空数值输入禁用保存及 Escape 取消；浏览器未报告错误或警告。

请求观察确认仅选中不写入，一次拖动只有一次 PATCH。历史新增本地矩形后，隔离库普通会话仍有原来的 2 个绘图，进度仍为 1199。

最终构建补验：1m / 5m 切换后拖动矩形上边，API 保存结果的两个时间戳、两个源序号均未改变，只有价格改变；隐藏和恢复后续行情仍正确投影。

50 / 200 / 500 个混合对象分别验证平移、缩放和推进；50 / 200 个对象的操作阶段未记录到新增超过 50 ms 的长任务。500 个对象以 100× 自动播放，已揭示数量从 1200 到 1237；出现 50～62 ms 长任务，自动化期间另记录约 0.94 / 1.00 s 停顿，来源未独立隔离。因此 **500 个密集混合对象是压力场景，不将投影微测或浏览器近期帧间隔当成整页稳定帧率的保证**；现有 Fib 标签、数据更新和浏览器测试环境也在此场景中。

375 / 1280 / 1440 / 1920 px 检查图表、工具菜单、对象窗口与设置弹窗。窄屏工具栏在自身区域横向滚动，设置弹窗内部滚动；新增控件复用基础组件，无新增 UI 规范例外。临时数据、日志、构建和截图均放在 Git 忽略目录，不提交。

## 工具菜单与快捷键调整

工具菜单移除矩形模板下拉框，模板仍在矩形设置内保存、应用和管理。矩形快捷键改为 `Shift + R`（Windows / Mac 通用），菜单提示与 ARIA 同步更新；旧 `Alt + R` 不再触发矩形，保留 `Alt + T/F`。输入框、弹窗和中文输入过程中继续屏蔽绘图快捷键。

本次调整验证：快捷键与推进队列相关 2 个文件、28 项测试通过，TypeScript、Lint 和隔离生产构建通过。在隔离测试库的浏览器页面确认菜单只有三个工具入口，`Shift + R` 启动、Escape 取消、`Alt + R` 不触发、数值输入框内不误启动；375 / 1440 px 菜单显示正常，浏览器未报告错误或警告。测试未重启当前业务服务。

## 样式弹窗与直接删除调整

取消普通与历史回放的矩形删除确认；与趋势线和斐波那契一致，直接调用已有删除流程，保留请求失败后的恢复与错误提示。模板删除也直接生效。同名模板覆盖保留原确认流程。

矩形弹窗改为与趋势线相同的 `max-w-md`，共用模板选择/删除、颜色与色值、透明度滑杆、线宽和线型控件。窄屏标签与控件上下排列；“保存模板”位于底部左侧，点击后再输入名称，取消名称或覆盖确认保留样式草稿。未修改图表绘制、投影与拖动更新逻辑。
