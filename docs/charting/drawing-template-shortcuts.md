# 绘图模板快捷键

> 文档状态：当前规范。适用范围：绘图模板的快捷键绑定、录入与快速应用；适用于普通回放和历史回放。

## 设置与清除

- 模板下拉列表每行包含名称、加减号按钮和灰色圆角键位框。点击名称选用样式并关闭列表；操作快捷键控件保持列表展开，不选用模板、不修改图表对象。
- 下拉宽度跟随模板控件所在区域（选择框与删除按钮），最大 20rem，以所属设置弹窗作为避让边界，避免伸出弹窗。长模板名称省略并保留完整名称提示；长快捷键和说明换行，列表过高时内部滚动。
- 点击列表外或再次点击模板选择框收起列表；点击设置弹窗标题或空白处只收起列表，不确认或取消样式。录入中收起列表会取消本次录入，保留原快捷键。列表内的绑定、清除和重新录入继续保持展开。
- 未绑定显示 `＋` 和“未设置”。点击 `＋` 或键位框显示“按下快捷键...”，捕获下一次有效组合；不限定 Alt + 数字，支持可识别的单键和 Ctrl / Alt / Shift / Command 组合。单独按修饰键继续等待，组合输入和长按重复不录入。使用物理键，数字行与小键盘分别记录，Mac Option 改写字符不改变绑定。
- 录入期间拦截按下与松开事件，暂停其他页面快捷键。Esc / Tab、关闭列表、点击外部、切换录入行、窗口失焦、页面隐藏及卸载取消录入，保留原绑定。取消录入不关闭外层设置弹窗。
- 有效组合通过检查后立即保存，显示 `－` 和键位。点击键位框重新录入；点击 `－` 立即解除绑定，保留模板，不弹确认框。
- 项目现有绘图工具、删除、回放推进/播放、数字切换周期，以及常见浏览器/系统组合和界面导航键不能绑定。同类模板不能重复，冲突时在该行说明原因，保持录入以便更换组合；不同绘图类型可复用，上下箭头分别计算。
- 按类型和模板 ID 保存到当前浏览器、当前站点的 `market-replay-drawing-template-shortcuts-v1`，与样式草稿独立。取消样式弹窗不撤销绑定或清除。同名覆盖保留 ID 和绑定；删除模板同时解除绑定，不改变其他模板编号。每类最多 50 个模板的原限制不变。
- 浏览器存储写入失败时就地说明“更改仅在本页有效”，当前页保留内存绑定，刷新不保证保留。其他标签页通过存储事件同步绑定，模板本体仍沿用各类型原有偏好流程。

## 快速应用

- 鼠标选中图表对象后，按该类型对应模板的快捷键更新选中对象样式。图表点击选择主动转移键盘焦点，避免先前输入框阻挡按键。
- 只更新选中对象样式，不改几何、文字正文、下一次绘图默认样式或其他对象。AB=CD 沿用设置面板的固定两条水平线归一规则。对象修改复用现有会话 PATCH、串行写入、失败恢复及错误提示，不改变交易、账户或回放进度。
- 无有效选中对象、隐藏绘图/对象、临时对象、绘图工具启用、拖动/测量手势、订单草稿或保存占用期间不应用。长按不重复保存。
- 输入框、原地文字编辑、组合输入、可见弹窗（包括 AI 窗口）、菜单和模板列表保留原有键盘交互。文字模板可以绑定；应用前须结束原地输入，再从对象窗口选中文字，正在输入时不应用。

## 识别边界与实现依据

- 冲突检查采用项目规则及常见浏览器/系统保留组合，Ctrl / Command 字母组合（含 Shift）等采用保守保留；不能枚举扩展或用户自定义系统热键。部分组合由浏览器或操作系统截获，网页无法收到；不能保证跨系统、浏览器与扩展环境均可用。无法录入时更换组合，不调用依赖安全上下文的键盘锁定等 API。
- 无数据库结构、迁移或安装升级步骤变化；已有模板不自动分配快捷键。
