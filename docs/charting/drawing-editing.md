# 绘图复制粘贴与撤销重做

> 文档状态：当前规范。适用范围：普通回放与历史回放的单对象复制粘贴、对象操作历史、恢复接口与并发保护。

## 复制粘贴

- Windows 使用 Ctrl+C / Ctrl+V；Mac 使用 Command+C / Command+V。仅处理已选中的单个已保存绘图，包含趋势线、斐波那契、矩形、文字、上下箭头和 AB=CD。输入框、文字编辑、弹窗、菜单、录制快捷键、拖动、测量或保存占用时保留原交互。
- 内部剪贴板仅存在当前页面内存，不读取或写入系统剪贴板、localStorage、sessionStorage 或 IndexedDB。刷新、卸载、切换数据集、会话或投影后清空；普通回放与历史回放不互通，也不跨标签页。
- 复制保存当时的完整对象快照；源对象之后修改或删除不改变快照。复制不修改图表、不入操作历史。粘贴包含完整几何、样式及文字，不改变模板或下一次默认样式。
- Ctrl+C 仅复制快照，Ctrl+V 才创建副本。鼠标必须位于图表价格窗格内且未被浮层遮挡，按粘贴立即创建；在窗格外按粘贴不执行，之后移入也不自动创建。没有预览或点击放置步骤，再按粘贴可继续使用同一快照。
- 多锚点对象按当前图表时间轴的 K 线位置统一平移，包围中心靠近鼠标并沿用 K 线对齐；各锚点使用同一个整根 K 线偏移，保留显示跨度与价差，避免休市或缺失行情改变副本长度。文字、箭头以定位锚点靠近鼠标。类型、样式及文字内容完整复制，不分别裁剪或缩放锚点。仅坐标、对象 ID 和保存时戳变化；平移后的自然时间跨度可能因休市变化。只使用已提供的共享图表时间轴，不新增完整行情接口。无法精确投影的旧插值锚点不静默取整改变形状。
- 切到高周期后，同一聚合 K 线内的不同源锚点保留可投影的桶内时间差，不合并为同一个保存锚点。提交前按创建规则检查副本；目标的部分时段或旧插值锚点无法同时保持投影和有效几何时不创建非法副本。
- 按粘贴时才读取当前视口坐标，并冻结副本位置、创建 UUID 和请求快照，保存期间不重复提交。结果未知或失败时保留冻结请求，鼠标在图表内再次按粘贴重试；使用相同 UUID 幂等确认，不再次创建或用移动后的鼠标位置覆盖首次请求。已提交请求不通过 Esc 撤回。未完成保存保留离页提示。
- 服务端明确拒绝创建的 4xx 响应解除本次请求占用，保留剪贴板供重新复制或粘贴；408 / 425 / 429、5xx、网络中断和成功响应内容无法确认的情况保留冻结请求。409 沿用冲突刷新与历史失效处理。
- 复制、粘贴、撤销和重做不在图表左下角显示操作、保存状态或失败提示浮层；沿用已有的保存保护与重试机制。

## 操作历史

- 每个打开的页面独立维护最多 100 步完整用户操作，不设快照字节容量上限，不按时间过期。仅内存保存，刷新、卸载和作用域切换清空；不同会话、标签页以及普通/历史回放不连续撤销。切换显示周期或外观不清空。
- 新建、粘贴、移动/缩放、删除、清空、正文及样式修改、模板应用和线宽快捷键均记录受影响对象的前后深拷贝快照。复制、选择、打开设置、未确认预览、取消和无变化操作不入历史。
- 一次拖动、一次样式确认、一次模板应用、一次独立线宽按键分别为一步。文字正文在一次原地编辑过程中合并自动保存，结束编辑后形成一步；打开样式设置时结束当前正文分组，确认设置独立记录，返回原地输入后建立下一组。输入框内的撤销重做保留浏览器原生行为。
- 一次清空无论包含多少对象都为一步，只记录本次实际删除的 ID 与完整快照；撤销恢复整组原 ID 和创建顺序，不替换整份当前列表，不删除其他页面随后新增的对象。恢复或再次删除整组均在同一 SQLite 事务中完成。
- 仅后端确认成功的修改进入历史；保存失败沿用原有恢复和错误提示。撤销/重做自身不生成新历史，成功后移动历史指针；失败保留原记录供重试。新操作清空重做分支，100 步预算涵盖同一条撤销/重做时间线。
- 撤销只恢复绘图对象，不撤销模板定义、快捷键绑定、默认绘图样式、图表偏好或交易/账户/回放状态。
- 工具栏下方在“对象窗口”按钮正上方依次放置撤销、重做按钮，悬浮和键盘聚焦显示当前对应操作及快捷键；无记录或操作占用时禁用。Windows 为 Ctrl+Z 撤销、Ctrl+Y 或 Ctrl+Shift+Z 重做；Mac 为 Command+Z / Command+Shift+Z。

## 保存与并发

- 各类创建沿用现有对象主键，可选 UUID `clientId` 支持幂等 POST；同 ID 只允许同数据集、同会话及同类型复用。已有记录重试不覆盖后续修改。浏览器 UUID 统一使用 `createUuid()`，兼容普通 HTTP。
- PATCH、单个 DELETE 和清空响应返回事务内实际生效的 `historyBefore` 快照，前端不以过期缓存代替；清空只返回本次实际删除对象的前快照。粘贴的冻结 POST 重试若发现同 ID 内容已被其他位置修改，返回冲突，不回写原快照。
- 对象写入和操作历史共用已有作用域串行队列。`POST /api/market-datasets/[id]/drawings/changes` 接收受影响对象的前后快照，在事务内验证全部对象的所属会话、预期内容和创建顺序，再整体应用；不单凭前端缓存判断。
- 若当前内容全部符合目标快照，视为上次成功后的幂等重试；符合操作前快照才执行修改。存在跨会话 ID、过期投影或其他位置修改造成的冲突时拒绝整组，不覆盖新数据；本页历史失效，重新读取对象。
- 更新时戳会随撤销重做改变，因此预期校验比较 ID、数据集、类型、原创建时间、几何和样式。恢复沿用原 ID 与创建时间；请求不包含其他会话对象或未受影响对象。
- 页面及作用域代次守卫阻止旧请求回填新页面或污染新历史；已授权请求仍可能在后端完成，遵循现有[文字保存契约](text-autosave-design.md)。只修改当前会话绘图，不产生交易命令或推进进度。
- 无 Prisma schema、数据库字段、迁移、新安装或升级步骤变化。会话保存与归档规则继续见[会话绘图持久化](archived-drawings.md)；模板录入与固定线宽组合见[绘图快捷键](drawing-template-shortcuts.md)。
