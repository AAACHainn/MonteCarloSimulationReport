# 箭头绘图

## 操作与存储

- 绘图工具中提供上箭头和下箭头，无工具快捷键。单击放置，尖端对齐时间和价格锚点；时间吸附显示 K 线，价格吸附最小跳动，完成后退出绘图模式，Escape 取消。
- 箭头固定为 19 px 高的实心图形，头部宽 16 px、尾部宽 8 px、尾部长 9 px，使用对象颜色填充，不随图表缩放改变大小；上箭头默认绿色，下箭头默认红色。双击箭头、双击对象名称或点击对象窗口的设置按钮打开同一个设置组件，样式只包含颜色。
- 两种方向分别保存默认颜色和模板，使用当前浏览器、当前站点的 localStorage；存储不可用时本页仍可使用。保存设置成功后才更新该方向的下一个箭头默认颜色。模板只保存颜色，支持保存、应用、同名覆盖确认和直接删除；每种方向最多 50 个，名称最多 50 字符。
- 点击选中后拖动，松开提交一次；仅选择、无变化或取消不提交。垂直拖动保留原时间及源序号，水平拖动保留原价格。Escape、窗口失焦或 pointercancel 取消拖动并恢复图表滚动。
- 对象窗口删除、Delete / Backspace 和清空均复用已有绘图流程，直接删除，失败恢复并提示。普通回放和历史交易回放共用会话后端存储，归档状态和跨会话隔离规则保持一致。
- 使用 `MarketDrawing.type` 的新值 `ARROW_UP` / `ARROW_DOWN`；`geometry` 保存单锚点 JSON，`style` 保存颜色 JSON。无需改变 Prisma schema、迁移或升级入口。旧代码不认识新类型，新增箭头后回退应用版本需要考虑绘图数据兼容性。

## 性能与验证范围

- 一个 Canvas primitive 管理全部箭头，没有逐对象 DOM 元素。分组只在绘图数组变化时更新；共用图表的 `DrawingTimelineLocator`、有界定位缓存和完整已加载时间轴，不复制交易日历计算。
- 屏幕坐标只在图表更新时投影；水平屏外箭头在价格投影之前跳过，垂直屏外箭头不绘制或命中。绘制裁剪限定在价格面板，箭头不参与价格轴自动缩放，图元卸载释放引用和缓存。
- 拖动期间使用 ref 预览，指针移动与绘图同步均通过动画帧合并。命中测试使用已投影的可见对象，不重新计算时间轴；纯箭头图表的空闲鼠标移动不增加动画帧任务。
- 自动回归覆盖上下箭头的 JSON 往返、类型和颜色校验、模板解析、不同周期投影、远距离日历缓存复用、10,000 个屏外对象裁剪、拖动合帧与单次提交、取消、双击设置和既有删除回调。真实 SQLite 回归覆盖 ACTIVE / ARCHIVED 会话的创建、移动、颜色保存、读取和删除，检查跨会话隔离及交易状态不变。
- 按用户要求不使用 Computer Use；桌面布局、实际 Canvas 外观和整页交互性能由用户验收。自动化中的图表替身与裁剪检查不能作为浏览器帧率保证。
