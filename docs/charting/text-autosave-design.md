# 文字原地编辑与自动保存

> 文档状态：当前规范。适用范围：当前文字编辑、自动保存与作用域隔离契约；文件名中的 design 不表示待实施计划。

日期：2026-10-21；整理日期：2026-10-30。本文说明当前文字编辑、自动保存与作用域隔离契约，用法及历史验收见 [文字绘图](text-drawing.md)。

## 交互

- Shift + T 后十字光标，点击价格窗格放置一个文本框。直接输入，没有确认/取消工具条；停止输入 700ms 后自动保存。新草稿为空时不创建对象。
- 右侧小方块拖动内容宽度，范围 120～800px，拖动期间只预览，松开保存；键盘左右键调宽，Shift 为 10px 步进。取消指针手势恢复原样式，不丢文字。
- 新默认外观开启换行、宽度 240px；旧对象、模板和已保存偏好保留原设置。拖宽时启用换行。正文内边距仍为 6px。
- Enter 换行；Ctrl/⌘ + Enter、Esc、点击外部在非空时保存最新内容再结束，清空文字时直接删除文本对象。从未发送的新空草稿直接退出，不发送请求。普通保存不显示文字框下方的保存状态，仅保留无障碍播报。
- 保存中仍可输入；失败保留输入并显示重试入口，不循环自动重试。继续编辑可再次触发防抖保存。中文组字、宽度拖动期间暂停提交。
- 只使用一种实线文字框外观：悬停时边框及右侧手柄为 50% 不透明度、鼠标手型，文字自身不降低透明度；单击松开立即进入输入，边框不透明，不再先选择或等待 500ms。没有虚线选择框或单独的左上锚点手柄。
- 未聚焦时在文字框内按住并移动至少 4 CSS px 才开始整体拖动，松开有变化时保存一次位置。未达到阈值即按单击处理。已聚焦时拖动用于文字选择，整体移动须先点外部结束输入再按住拖动。取消或失焦中断拖动恢复原位置。
- **颜色、字号、背景、边框及模板仍在原有设置弹窗中管理**，不改为工具栏。与其他绘图一致，双击图表文字或原地编辑框打开样式弹窗；保留 Alt + Enter 和对象窗口设置按钮。右键不再打开样式，文本域保留浏览器复制/粘贴菜单。先保存原地编辑版本，再建立弹窗检查点；弹窗内暂停自动保存，确认后提交并返回原地编辑，取消恢复检查点。直接从图表或对象窗口打开的弹窗仍确认后关闭。
- 隐藏绘图、切换工具和受控会话切换先完成当前有效保存，失败则留在编辑状态。删除/清空丢弃尚未提交的编辑版本，并等待在途写入后删除；不因编辑器先保存而复活对象。
- 不持久化浏览器文字草稿。存在未完成写入时使用浏览器离页提示；浏览器关闭、强制卸载或断电不承诺最后一次写入完成。

## 保存与隔离

每个编辑器拥有独立的 `TextAutosave`、稳定创建 UUID、最新可编辑版本和服务端确认版本；最多一个在途写入。响应只更新确认版本和对象 ID，不覆盖用户在请求期间继续输入的内容。显式结束会等待在途写入，并保存其后的最新版本。

TEXT POST 可携带 `clientId`，通过现有对象主键原子 upsert，不增加数据库字段或迁移。创建快照及 UUID 在首次提交后固定；响应不明时以相同快照重试，收到实际服务端记录后再 PATCH 最新草稿。已有记录只允许相同数据集、会话和 TEXT 类型复用，冲突返回 409，不返回其他作用域内容。重复 POST 不覆盖已有内容或更新时间。

普通和历史回放复用实际对象返回接口，并通过共享的会话作用域写入队列协调创建、更新、删除和清空。队列涵盖读取最新集合、请求和结果合并，防止旧快照覆盖另一写入；不改变已有绘图的乐观交互。

请求守卫包含作用域及编辑器代次，覆盖 A → B → A、关闭后重开和卸载；预览、控制句柄及清理按编辑器 owner 判断归属。首次创建接收 ID 时保持 editor key 与 DOM，不因响应重建输入框或移动光标。过期响应可以完成已授权的后端写入，但不能回填新会话或新编辑器。

普通绘图更新使用独立的作用域守卫，只跟踪数据集、会话、投影及组件卸载，不随文字编辑器打开、关闭或隐藏而失效；请求入队前捕获守卫，执行前及响应后再次校验，避免队列跨作用域回填。文字自动保存继续使用编辑器代次守卫。

清空后的退出是删除事务：暂停防抖保存，等待在途创建/修改完成；创建结果未知时先用原 clientId 和冻结快照确认实际对象，再删除实际 ID。删除沿用作用域写入队列及请求守卫，成功后移除列表对象并关闭编辑器，刷新不会恢复。重复退出共用一个删除请求；删除期间暂时禁用输入，防止晚到输入重新触发保存。仅真实网络或删除失败时保留输入和重试入口；重复删除返回 404 视为成功。未发送过的空草稿无需创建或删除请求。

## 性能与 UI

保留一个共享 Canvas primitive 和有界排版缓存。只有当前编辑对象挂一个 DOM 文本框，Canvas 暂停其绘制和命中；输入不重建整个绘图集合。拖宽按 rAF 合并，只在内容、字体、宽度或容器变化时更新输入高度，没有持续动画、逐对象 DOM 或轮询。

悬停使用缓存后的命中区域及已有指针 rAF，只有悬停目标变化才请求重绘，不触发文字重新测量，也不挂载逐对象 DOM。Canvas 悬停框与 DOM 输入框使用同一实线颜色和右侧手柄位置；输入框用 outline 避免边框占据内容宽度。Canvas 切换到文本域可能改变原生双击的目标，因此只记录首击坐标、时间和对象 ID，在第二次按下时衔接双击样式入口；没有延时任务或持续计时器。旧延迟单击实现及测试已移除。

原地框蓝色边界仅为编辑态，持久化背景/边框仍受样式控制。右侧 8px 方块提供 40px 命中区域、中文名称及范围语义。保存状态和错误在附近播报，成功不弹窗。窄窗格保留局部滚动，编辑框避让不改写时间价格锚点。原生文本域折行与 Canvas 字素排版存在浏览器字体差异，不保证任意 Unicode 文本逐像素一致。

## 独立审阅

按用户要求由一位子代理只读审阅现有实现与方案；与主代理讨论后采纳以下约束，无剩余阻塞意见：

1. 显式传入对象 ID，返回服务端实际记录；创建 ID 接收与编辑器实例生命周期分离。
2. 结束编辑必须 flush 最新版本；样式弹窗有独立检查点与确认/取消事务边界。
3. 代次守卫覆盖同作用域重返，清理按 owner；删除等待在途写入，全部绘图写入共用作用域队列。
4. 创建使用原子幂等 ID 和冻结快照，重试不重复创建、不覆盖后续修改，并校验数据集/会话/类型归属。
5. 自动换行兼容旧对象；拖宽 rAF 合并、取消恢复宽度，中文组字暂停；卸载不伪造保存成功。

复杂状态机与作用域生命周期补充单测；API 以独立 SQLite 覆盖并发幂等、冲突及无交易副作用。浏览器以独立 TEST 行情验证延迟、失败恢复、原地续写、弹窗事务与刷新持久化。真实性能及视口覆盖限制沿用验收文档，不以合成基准替代整页帧率结论。
