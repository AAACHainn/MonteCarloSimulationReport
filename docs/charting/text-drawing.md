# 文字绘图：使用与验收记录

实施日期：2026-10-21。设计及独立审阅意见见 [文字绘图设计](text-drawing-design.md)。

自动保存交互及本次独立审阅见 [原地编辑与自动保存方案](text-autosave-design.md)。以下“使用”描述当前行为；后面的历史验收按当时版本记录，初版 Esc 取消、确认保存等行为已被本次自动保存方案替代。

## 使用

在普通回放或历史回放中，选择“绘图工具 → 文字”，或按 **Shift + T**，光标变为十字，单击价格区域后在该位置直接出现可输入的文本框。停止输入 700ms 后自动保存到后端，保存期间仍可继续输入；右侧小方块可拖动调整宽度，松开后保存。Enter 换行，Ctrl/⌘ + Enter、Esc 或点击外部保存并结束编辑；Esc 不撤销已经自动保存的内容。空白新草稿退出时不创建对象，已有文字被清空时须补回有效内容或直接删除对象。保存失败、内容无效时保留输入框，失败后可继续编辑或点击重试。输入框、中文组字以及打开的弹窗会屏蔽绘图快捷键。

设置面板复用趋势线、斐波那契的 Dialog、模板、颜色、透明度和按钮组件，支持颜色、12～48 px 字号、粗体、斜体、背景及透明度、1 px 边框、自动换行。背景、边框初始关闭，新默认样式开启自动换行、内容宽度 240px；已有对象、模板及浏览器偏好中的换行设置保留。内容宽度可设为 120～800 px；Enter 始终插入手动换行。最多 2000 个 UTF-16 单元、50 个手动行，空白内容不能保存。

鼠标移到文字框范围时显示 50% 不透明度的实线边框及右侧手柄，文字颜色不变，光标为手型。单击松开立即原地编辑，边框变为不透明实线；没有虚线选择框或单击延时。未聚焦时按住并移动超过 4px 才整体拖动；已聚焦时拖动选择文字，要移动整个框先点击外部结束输入。**双击文字框打开样式弹窗，与其他绘图一致**；编辑时也可按 Alt + Enter，或使用对象窗口的设置按钮。右键不再打开样式。打开前先保存原地编辑内容；弹窗内继续使用确认/取消，从原地编辑打开时，确认后保存并返回原地编辑，取消恢复打开弹窗时的内容与样式，不回滚此前自动保存。Delete / Backspace 沿用已有直接删除操作；隐藏绘图和清空本会话同样包含文字。已归档会话也可编辑文字，内容和位置保存到后端所属会话。保存成功的外观成为下次默认样式。

模板只含外观，不含文字和位置。模板及默认外观保存在独立浏览器偏好键 `market-replay-text-preferences-v1`，最多 50 个模板，名称最多 50 字符；同名保存替换。命名弹窗返回时保留文字草稿，取消对象不撤销已完成的模板保存。浏览器偏好不可用时仍可绘制和保存后端对象。

## 实现与性能边界

- 一组文字共用一个 Canvas primitive，不为每个对象建立 DOM、series 或逐对象监听器。不扩展价格自动缩放。
- 只有当前编辑对象临时使用一个 DOM 文本框，Canvas 暂停绘制及命中该对象，避免叠画；输入期间不重复测量它的 Canvas 排版。图表坐标订阅纳入原有 rAF，仅当前编辑器更新位置，不引入持续动画。
- 时间定位复用共享时间轴；拖动通过现有 rAF 合并，移动过程中只更新预览，松开且有变化才发一次 PATCH。单轴拖动保留另一维度的原始锚点。
- 新建对象在 POST 期间只显示独立草稿，成功后接收服务端实际 ID，不重建输入框；不会额外追加临时乐观文字。自动保存串行合并最新内容，每个会话的绘图写入共用队列，避免保存与删除相互覆盖。TEXT 创建以稳定 UUID 幂等，响应不明时重试不会重复创建。会话、投影或编辑器切换丢弃过期界面响应。
- 排版按内容、字体和有效换行宽度缓存。颜色、选中和平移不触发重新测量。缓存最多 512 条、估算 8 MiB，以整段字符串和紧凑行偏移保存，删除、切会话和卸载时释放。字体加载完成会使缓存失效。
- 绘制和命中共用包围盒，包含粗斜体字形外伸。裁剪到价格区域，屏外对象跳过绘制，长文只绘制可见行；正文处于既有线条和编辑句柄下方。

这不是无限对象或稳定 60 FPS 的承诺。首次载入大量不同长文仍需同步排版；独立 PDF / AI 快照目前和其他绘图一样，不自动包含文字。

## 浏览器检查与待测项

最终生产构建在隔离端口 3129、TEST 合成行情验收，真实窗口为 1280 × 720，DPR 1.5：

- 普通及归档历史页面可新建，刷新后对象存在；历史对象拖动刷新保留位置，双击及对象窗口可打开设置。
- 多行中文、粗体、斜体、背景、边框、自动换行、无效宽度禁用确认、模板保存返回保留草稿已检查。
- 保存失败注入后保留输入，重试成功；请求记录中一次拖动只产生一次 PATCH。取消新建不出现在对象列表且不发送创建请求。
- 最终构建打开文字面板后焦点直接位于文字输入框。1280px 下扩展设置可在弹窗内部滚动，确认与取消可通过键盘或滚动到达。
- 200 个专用文字对象加载、图表平移和缩放后没有浏览器警告或错误；压力对象随后仅在独立测试库内逐条清理。

**UI 检查例外：** 浏览器自动化的视口覆盖命令返回后，DOM 的 `innerWidth/innerHeight` 和截图始终仍为 1280 × 720，因此没有将 375 / 1440 / 1920px 记为已验证。面板沿用共享响应式 Dialog 和窄屏单列布局，仍需在支持实际调整尺寸的浏览器补充视觉验收。

**性能待测：** 当前浏览器只读接口不提供 `requestAnimationFrame`、`performance` 或 `PerformanceObserver`。没有取得设计要求的 30 秒交互帧 P95、长任务归因、播放对照或真实 Canvas 单对象重排耗时；不能将上述合成结果当作整页帧率结论。

本轮普通页面验收为激活后的 TEST 会话，既有页面加载会执行进度同步与交易历史兼容整理，不能将整轮浏览器操作后的全表摘要作为“所有交易表逐字节不变”的证据；绘图 API 的无交易副作用由隔离集成测试单独验证。业务数据库未用于验收。

## 双击样式入口统一

## 审查后修复请求生命周期

2026-10-21 修复两个审查问题：普通绘图 PATCH 改用独立会话作用域守卫，文字编辑器的打开、关闭或隐藏不再跳过响应处理、失败回滚与 pending 清理；守卫在入队前捕获，仍拒绝作用域更换、重返旧作用域及卸载后的旧请求。

文字创建曾发送但结果未知时，清空草稿不能再直接退出。显式退出先以原 clientId 和创建快照确认实际对象，保留当前空输入并阻止退出；补回有效内容后可修改已确认对象，也可直接删除。未曾发送的新草稿仍可直接取消。未确认的创建保持 dirty，失败保留输入且不自动循环重试。

相关 3 个文件、30 项回归通过，覆盖普通写入守卫与文字编辑生命周期分离、A → B → A/卸载隔离、创建响应丢失后清空、恢复失败、在途创建被清空和首次防抖前清空。本次为请求状态修复，没有改变文字框样式或鼠标操作。
