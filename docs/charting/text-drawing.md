# 文字绘图：使用与验收记录

实施日期：2026-10-21；使用说明整理日期：2026-10-30。本文保留当前用法、实现边界与有用的历史验收记录。

保存与交互契约见 [原地编辑与自动保存](text-autosave-design.md)。以下“使用”描述当前行为；后面的验收数字仅代表各阶段当时的结果，不作为当前版本已复测的证明。

## 使用

在普通回放或历史回放中，选择“绘图工具 → 文字”，或按 **Shift + T**，光标变为十字，单击价格区域后在该位置直接出现可输入的文本框。停止输入 700ms 后自动保存到后端，保存期间仍可继续输入；右侧小方块可拖动调整宽度，松开后保存。Enter 换行，Ctrl/⌘ + Enter、Esc 或点击外部保存并结束编辑；文字清空后退出会直接删除对象，不再提示“请输入非空文字”。未发送过的空白新草稿直接退出，不创建对象。普通保存没有可见状态文字；真实保存/删除失败及非空内容超出限制时仍保留输入和错误恢复。输入框、中文组字以及打开的弹窗会屏蔽绘图快捷键。

设置面板复用趋势线、斐波那契的 Dialog、模板、颜色、透明度和按钮组件，支持颜色、12～48 px 字号、粗体、斜体、背景及透明度、1 px 边框、自动换行。背景、边框初始关闭，新默认样式开启自动换行、内容宽度 240px；已有对象、模板及浏览器偏好中的换行设置保留。内容宽度可设为 120～800 px；Enter 始终插入手动换行。最多 2000 个 UTF-16 单元、50 个手动行，空白内容不能保存。

鼠标移到文字框范围时显示 50% 不透明度的实线边框及右侧手柄，文字颜色不变，光标为手型。单击松开立即原地编辑，边框变为不透明实线；没有虚线选择框或单击延时。未聚焦时按住并移动超过 4px 才整体拖动；已聚焦时拖动选择文字，要移动整个框先点击外部结束输入。**双击文字框打开样式弹窗，与其他绘图一致**；编辑时也可按 Alt + Enter，或使用对象窗口的设置按钮。右键不再打开样式。打开前先保存原地编辑内容；弹窗内继续使用确认/取消，从原地编辑打开时，确认后保存并返回原地编辑，取消恢复打开弹窗时的内容与样式，不回滚此前自动保存。Delete / Backspace 沿用已有直接删除操作；隐藏绘图和清空本会话同样包含文字。已归档会话也可编辑文字，内容和位置保存到后端所属会话。保存成功的外观成为下次默认样式。

模板只含外观，不含文字和位置。模板及默认外观保存在独立浏览器偏好键 `market-replay-text-preferences-v1`，最多 50 个模板，名称最多 50 字符；同名保存替换。命名弹窗返回时保留文字草稿，取消对象不撤销已完成的模板保存。浏览器偏好不可用时仍可绘制和保存后端对象。

## 数据与兼容

- 复用 `MarketDrawing` 的 `type`、`geometry`、`style` 文本字段及会话索引，无新增结构迁移。`TEXT` 的 geometry 包含单一 `anchor` 和纯文本 `text`，style 使用独立文字样式；内容不混入模板或对象 ID。
- 内容将 CRLF / CR 规范为 LF，前后端统一校验长度、行数与非空白限制，保留有效内容的空格与换行；以纯文本显示，不解析 HTML、Markdown 或脚本。类型、默认样式与校验见 [chart-drawings.ts](../../lib/market-replay/chart-drawings.ts)。
- 创建、修改、删除沿用会话隔离、投影身份、纠错锁及归档绘图写入校验；文字编辑不改变交易、账户或回放进度。普通 HTTP 的临时 UUID 使用统一 [createUuid](../../lib/uuid.ts)。
- 旧应用可能不识别 `TEXT`，无结构迁移不代表可直接回退旧代码；按[升级与回退指南](../operations/upgrade.md)保留备份，不通过删除文字对象规避兼容问题。

## 实现与性能边界

- 一组文字共用一个 Canvas primitive，不为每个对象建立 DOM、series 或逐对象监听器。不扩展价格自动缩放。
- 只有当前编辑对象临时使用一个 DOM 文本框，Canvas 暂停绘制及命中该对象，避免叠画；输入期间不重复测量它的 Canvas 排版。图表坐标订阅纳入原有 rAF，仅当前编辑器更新位置，不引入持续动画。
- 时间定位复用共享时间轴；拖动通过现有 rAF 合并，移动过程中只更新预览，松开且有变化才发一次 PATCH。单轴拖动保留另一维度的原始锚点。
- 新建对象在 POST 期间只显示独立草稿，成功后接收服务端实际 ID，不重建输入框；不会额外追加临时乐观文字。自动保存串行合并最新内容，每个会话的绘图写入共用队列，避免保存与删除相互覆盖。TEXT 创建以稳定 UUID 幂等，响应不明时重试不会重复创建。会话、投影或编辑器切换丢弃过期界面响应。
- 排版按内容、字体和有效换行宽度缓存。颜色、选中和平移不触发重新测量。缓存最多 512 条、估算 8 MiB，以整段字符串和紧凑行偏移保存，删除、切会话和卸载时释放。字体加载完成会使缓存失效。
- 绘制和命中共用包围盒，包含粗斜体字形外伸。裁剪到价格区域，屏外对象跳过绘制，长文只绘制可见行；正文处于既有线条和编辑句柄下方。

这不是无限对象或稳定 60 FPS 的承诺。首次载入大量不同长文仍需同步排版；独立 PDF / AI 快照目前和其他绘图一样，不自动包含文字。

## 自动验证

本地 Windows / Node，使用项目锁定依赖及独立 SQLite 测试库：

- 完整测试：127 个测试文件通过，1 个跳过；1185 项通过，2 项跳过。
- 随后增加弹窗初始焦点和中文组字 Esc 保护，相关 3 个文件、38 项测试再次通过（包含新增 2 项）。
- `corepack pnpm lint` 通过；最终隔离生产构建通过，包含 TypeScript 校验。构建输出位于忽略的临时目录，未替换业务构建或重启业务服务。
- API 集成测试覆盖 ACTIVE / ARCHIVED 的文字创建、读取、修改、删除，拒绝错类型 geometry/style，核对交易表没有被绘图 API 改动。既有三类绘图、历史请求隔离、快捷键回归通过。

运行 `corepack pnpm run benchmark:text-drawings` 可复现合成基准。它注入文字度量，只测布局、坐标投影和命中，不包括真实 Canvas、React、HTTP 或数据库；每组采样 100 次热更新。混合场景四类对象轮流分配。

| 场景 | 总对象数 / 文字数 | 首次更新 ms | 热更新 P95 ms | 单对象编辑 ms |
| --- | --- | --- | --- | --- |
| 混合短文 | 50 / 13 | 1.28 | 0.41 | 0.06 |
| 混合短文 | 200 / 50 | 1.14 | 1.18 | 0.10 |
| 混合短文 | 500 / 125 | 2.06 | 2.39 | 0.31 |
| 混合长文 | 50 / 13 | 16.29 | 0.26 | 1.34 |
| 混合长文 | 200 / 50 | 62.03 | 1.19 | 1.24 |
| 混合长文 | 500 / 125 | 155.54 | 2.38 | 1.32 |
| 纯长文 | 200 / 200 | 253.12 | 0.44 | 1.60 |
| 纯长文 | 500 / 500 | 614.81 | 0.91 | 1.70 |

长文约 1900 字符、120 px 自动换行。所有组热更新新增文字测量次数为 0；500 段长文缓存估算 4,319,184 字节。冷启动明显超出单帧预算，不能用热更新结果掩盖首次排版成本。200 个混合对象热更新达到设计的 4ms 合成目标。

## 浏览器检查与待测项

最终生产构建在隔离端口 3129、TEST 合成行情验收，真实窗口为 1280 × 720，DPR 1.5：

- 普通及归档历史页面可新建，刷新后对象存在；历史对象拖动刷新保留位置，双击及对象窗口可打开设置。
- 多行中文、粗体、斜体、背景、边框、自动换行、无效宽度禁用确认、模板保存返回保留草稿已检查。
- 保存失败注入后保留输入，重试成功；请求记录中一次拖动只产生一次 PATCH。
- 最终构建打开文字面板后焦点直接位于文字输入框。1280px 下扩展设置可在弹窗内部滚动，确认与取消可通过键盘或滚动到达。
- 200 个专用文字对象加载、图表平移和缩放后没有浏览器警告或错误；压力对象随后仅在独立测试库内逐条清理。

**UI 检查例外：** 浏览器自动化的视口覆盖命令返回后，DOM 的 `innerWidth/innerHeight` 和截图始终仍为 1280 × 720，因此没有将 375 / 1440 / 1920px 记为已验证。面板沿用共享响应式 Dialog 和窄屏单列布局，仍需在支持实际调整尺寸的浏览器补充视觉验收。

**性能待测：** 当前浏览器只读接口不提供 `requestAnimationFrame`、`performance` 或 `PerformanceObserver`。没有取得设计要求的 30 秒交互帧 P95、长任务归因、播放对照或真实 Canvas 单对象重排耗时；不能将上述合成结果当作整页帧率结论。

本轮普通页面验收为激活后的 TEST 会话，既有页面加载会执行进度同步与交易历史兼容整理，不能将整轮浏览器操作后的全表摘要作为“所有交易表逐字节不变”的证据；绘图 API 的无交易副作用由隔离集成测试单独验证。业务数据库未用于验收。

## 2026-10-21 的交互演进与修复

下表保留改变方案或修复竞态的原因；完整当前交互见上方“使用”，保存与隔离契约见[自动保存规范](text-autosave-design.md)。各行检查仅对应该次改动，不代表当前版本重新复测，也不把前一轮完整回归数字累加为新结果。

| 阶段 | 决策或问题 | 当时记录的检查 |
| --- | --- | --- |
| 原地编辑 | 放置后直接在图表输入；区分放置点击与结束编辑，避免首击立即关闭 | 5 文件、57 项；隔离 1280×720 浏览器 |
| 价格窗格底部 | 修正成交量独立窗格后的可用高度，避免价格区底部无法编辑；边界变化不额外测量文字 | 28 项及隔离浏览器 |
| 自动保存与拖宽 | 冻结创建快照和 UUID、接收实际 ID、弹窗检查点、串行队列与编辑器代次分离 | 全量 1211 通过、2 跳过；后续 20 项；API 集成 43 项 |
| 双击与单击 | 双击统一样式入口；后续取消延迟单击、虚线框和独立锚点，采用即时输入与拖动阈值 | 双击调整 48 项；即时单击相关 52 项，全量 1219 通过、2 跳过 |
| 普通写入守卫 | 文字编辑器关闭曾使普通 PATCH 响应被忽略；改用独立会话作用域守卫，覆盖 A → B → A 和卸载 | 3 文件、30 项 |
| 未知创建与删除 | 响应丢失后清空不能直接退出；先用原创建身份确认，再串行删除，避免晚到创建复活文字 | 生命周期回归及清空删除相关 4 文件、42 项；404 重复删除视为成功 |

这些轮次记录 lint 和隔离生产构建通过，使用 TEST 合成行情与独立数据库；未用业务库做删除或故障试验。自动保存阶段合成热更新 P95：200 个短/长文混合对象为 1.30/1.39ms，500 个为 2.80/2.60ms；500 段纯长文首次布局 633.06ms、热更新 P95 0.83ms。它们仍不包含真实 Canvas、React、网络或整页帧率。

历史浏览器操作主要为 1280×720、DPR 1.5；其他尺寸、帧采样与系统减少动画的未测边界沿用前文。已移除逐次重复的点击、启动和手动复验步骤；完整演进可通过本文件 Git 历史追溯。
