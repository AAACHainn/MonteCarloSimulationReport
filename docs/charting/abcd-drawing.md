# AB=CD 等幅测量

> 文档状态：当前规范。适用范围：AB=CD 绘图的操作、数据与边界。

## 操作

- 左侧绘图工具选择“AB=CD 等幅测量”，或按 `Alt + W`（Mac：`Option + W`）。项目现有快捷键未占用该组合；使用物理 `KeyW` 识别 Option 改写字符的键盘。输入框、可见弹窗、组合输入和已处理事件不触发，忽略按键重复。
- 依次单击 A、B、C；先预览 AB，再预览 BC 与投影水平线，第三次有效点击后才创建对象。Escape 取消，无中途数据库记录。水平 AB 或 B/C 时间相同不提交，仍可重新选点。
- 计算使用真实价格：`D.price = C.price + (B.price − A.price)`。上涨 AB 向上投影，下跌 AB 向下投影。固定 C、D 两条水平线；两条线的横向范围是 B、C 的显示时间坐标，不外推虚构的 D 时间。
- 绘制 A→B→C 辅助线，只显示 A、B、C 控制点，不画 D 点。选中后可整体拖动或单独拖动任一控制点；C 改变时同步更新两条水平线位置，A/B 改变时重新计算投影高度，B/C 改变时间时更新线宽。
- 双击图表对象、双击对象名称或点击对象窗口的设置按钮打开设置。使用独立 AB=CD 设置面板，仅参考已有面板布局，提供统一颜色、线宽、线型、显示价格和 C / D 标签。C、D 位置由等幅公式固定，不提供比例编辑或逐级配色。历史样式 JSON 保持可读取；在此面板编辑或保存时归一为同色的 C、D 两条线。
- 默认蓝色实线，不显示价格/水平位标签。默认样式和模板独立于斐波那契，保存在当前浏览器站点。保存设置成功后更新下一次默认样式；模板沿用现有面板的保存、覆盖同名和删除规则，每类最多 50 个、名称最多 50 字符。
- 对象保存、直接删除、清空及失败恢复复用现有绘图流程。普通回放和历史交易回放共用后端会话存储；归档绘图可编辑，交易记录和回放进度保持只读约束。

## 数据与性能

- 复用 `MarketDrawing.type` / `geometry` / `style` 字符串字段。新增类型值 `AB_CD`，几何 JSON 存储 `a`、`b`、`c` 三个时间/源序号/价格锚点，样式 JSON 采用现有水平位样式。无需 Prisma 字段、迁移或新升级脚本，不修改 v1.0 基线及旧升级入口。旧应用不识别新类型，已有 AB=CD 数据时回退版本需要考虑兼容性。
- 一个 Canvas primitive 管理全部 AB=CD 对象，复用完整已加载时间轴、共享 `DrawingTimelineLocator`、二分索引、有界缓存及交易日历，不读取完整源行情，不改动撮合或账户数据。
- 水平完全离屏的对象在价格投影前跳过；各段按有限线段与视口相交判断裁剪，端点均离屏但穿过视口的线段继续保留。Canvas 限制在价格面板内；无价格轴自动缩放贡献。关闭标签时不测量文字，不绘制标签背景。
- 指针移动与绘图同步按动画帧合并，拖动中只更新 ref 预览，松开时保存一次；无变化、取消、失焦和 pointercancel 不提交。纯 AB=CD 场景的空闲鼠标移动不增加指针动画帧。切换作用域及卸载清理草稿、预览和待处理帧。
- 单独移动价格时保留原时间及源序号；只改时间时保留价格。显示周期改变只重新投影，持久化锚点不重写。

## 验证范围

自动回归覆盖有向等幅计算、退化/非有限几何校验、三步放置及预览、模板解析、C/D 水平线范围、仅三个控制点、拖动合帧及单次保存、取消恢复、Alt/Option+W、跨周期定位、远距离日历缓存复用与 10,000 个屏外对象裁剪。既有 SQLite 会话集成测试扩展到 AB=CD 的 ACTIVE / ARCHIVED 保存、样式更新、刷新读取、类型拒绝、跨会话拒绝、直接删除及交易状态不变。

按用户偏好不使用 Computer Use，实际外观、1280/1440/1920 桌面布局及整页浏览器性能由用户验收。图表替身、裁剪和缓存回归不能作为浏览器帧率保证。
