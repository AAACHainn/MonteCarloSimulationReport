# 文字绘图工具设计

日期：2026-10-21。状态：已按独立审阅后的方案实施。本文保留设计目标与验收计划；实际完成项、测量结果和待验证边界见 [使用与验收记录](text-drawing.md)，不能将本文中的目标直接视为实测结论。

## 1. 目标与范围

在普通回放、历史复盘和已归档会话的“绘图工具”中新增“文字”，快捷键为 **Shift + T**。按用户后续要求，点击图表后直接在点击处的文本框输入；样式仍在统一风格的设置弹窗调整。文字可选择、拖动、编辑、直接删除，并随所属会话保存到后端。

本期包含纯文本、多行、颜色、字号、粗体、斜体、可选背景与边框、自动换行、样式模板。不增加“可见范围”页签、富文本、链接执行、图片、旋转、引线或固定在屏幕角落的模式。文字随时间和价格移动，字体大小使用 CSS 像素，不随 K 线缩放变大或变小。

设计遵守 [UI 规范](../ui/ui-guidelines.md)，复用 [矩形交互与性能方案](rectangle-drawing.md) 和 [会话绘图持久化](archived-drawings.md)。不改变交易、账户、回放进度、行情窗口或其他绘图的业务规则。

## 2. Lightweight Charts 能力核对

已核对 [项目依赖](../../package.json) 及本地安装包的 `dist/typings.d.ts`：当前使用 `lightweight-charts@5.2.0`。

| 官方能力 | 可复用的部分 | 对本需求的限制与选择 |
| --- | --- | --- |
| [createTextWatermark](https://tradingview.github.io/lightweight-charts/docs/api/functions/createTextWatermark) / [文字选项](https://tradingview.github.io/lightweight-charts/docs/api/interfaces/TextWatermarkLineOptions) | 颜色、字号、字体、多行配置 | 按窗格对齐，单行文字不自动换行；不适合作为绑定时间、价格的可拖动对象 |
| [SeriesMarkerPrice](https://tradingview.github.io/lightweight-charts/docs/api/interfaces/SeriesMarkerPrice) | 时间、指定价格和 `text` 标记 | 面向系列标记，没有本需求完整的文字框样式与编辑交互 |
| [官方插件示例](https://tradingview.github.io/lightweight-charts/plugin-examples/) | 包含 Anchored Text 示例，可参考文字渲染方式 | 示例不等于项目已安装或具备完整的文字绘图工具；本期不引入新插件依赖 |
| [ISeriesPrimitive](https://tradingview.github.io/lightweight-charts/docs/plugins/series-primitives) | Canvas 绘制、生命周期、命中检测、图表/系列坐标转换 | 采用此扩展点，与现有趋势线、矩形保持一致；项目实现文字排版、设置、交互和持久化 |

选型结论：新增一个管理全部文字对象的 `TextDrawingPrimitive`，复用图表、坐标转换和现有绘图基础设施，不为每段文字创建系列、primitive 或 DOM 节点。库有文字显示能力，但本地类型声明中没有直接提供本需求的完整文字编辑工具。

## 3. 用户交互

### 3.1 新建

1. 点击“绘图工具 → 文字”，或按 Shift + T；关闭菜单、取消测量模式、显示绘图层、清除当前选择，与其他工具一致。
2. 光标变为十字，进入待放置状态。此阶段不创建对象，不跟随鼠标渲染占位文字，不发请求。
3. 在主价格窗格单击一次，复用现有锚点换算：时间吸附显示 K 线，价格吸附最小跳动；未来空白区域继续使用现有时间轴定位规则。坐标无法解析时保持待放置状态。
4. 固定锚点，退出待放置状态，经独立的 `onPlaceText(anchor)` 回调在图表内显示一个自动聚焦的文本框。该阶段只有本地待编辑草稿，内容初始为空，样式取当前文字默认样式；空白内容不能确认。不能把仅有 anchor 的放置事件送入现有两点工具的 `onCreateDrawing(type, geometry)`，也不能伪造合法 `TextGeometry`。
5. 输入与样式调整只影响当前前端预览；确认、Ctrl/⌘ + Enter 或点击外部结束非空编辑时，一次 POST 保存内容、锚点和样式。Enter 换行，中文组字时不执行保存或取消快捷键。成功后选中新对象，并更新下一次默认样式；失败保留输入，显示错误，允许重试或取消。空白草稿点击外部直接取消。
6. 放置前按 Escape 退出；放置后点击取消、关闭或按 Escape，清除预览，不产生空对象或后端记录。完成一次后不连续创建。

输入框、可编辑元素、任何可见对话框和中文输入法组字过程中，均不触发绘图快捷键。自动重复 keydown 不重复激活。Shift + T 只接受 Shift 修饰，额外 Alt / Ctrl / Meta 不触发；优先识别 `event.code === "KeyT"`，保留现有无 code 回退规则。

快捷键解析改为返回明确工具动作，例如 `"TREND_LINE" | "FIB_RETRACEMENT" | "RECTANGLE" | "TEXT" | null`，避免把 Alt + T 与 Shift + T 都简化成同一个 `"t"`。普通页、历史页、菜单提示和 `aria-keyshortcuts="Shift+t"` 同步使用映射，保留 Alt + T/F 与 Shift + R。

### 3.2 选择、移动、编辑与删除

- 文字外框左上角为单一时间/价格锚点；内容区固定内边距 6 CSS px，背景、边框开关不改变锚点。关闭自动换行时，框宽取最长手动行的排版宽度；开启时按设定内容宽度排版，高度随行数增长。
- 无背景、无边框时，完整文字包围盒仍可命中。单击选择，显示临时蓝色选中框与锚点控制点；这些编辑标记不持久化。按住正文框或锚点拖动整体位置；本期不增加缩放控制点。
- 拖动仅更新 ref 中的位置预览，每帧处理最新指针位置，松开才提交一次 PATCH。点击未移动、回到原位、Escape 取消或 pointercancel 不提交；结束时恢复图表滚动并释放指针捕获。
- 在高周期视图仅上下拖动时保留原时间戳和源序号；仅左右拖动时保留原价格。不能因为重新吸附而改写用户没有编辑的维度。
- 双击图表正文框直接原地编辑，Canvas 暂时隐藏该对象以免叠画。对象窗口名称双击或设置按钮打开完整设置；原地编辑框也提供设置入口，切换时保留内容草稿。对象窗口显示“文字 N · 首行摘要”，摘要最多 24 个 Unicode 字符；不向每个对象添加常驻 DOM 编辑器。
- Delete / Backspace 与删除按钮直接删除，失败恢复对象并提示；文本框内的删除键只删除字符。文字参与现有“清空本会话绘图”，不增加确认弹窗。
- 订单控件与测量手势优先，其后依次为选中绘图控制点、现有线段/边框、文字正文框、选中矩形内部。文字相互重叠时选中对象优先，否则按后创建的对象优先；渲染顺序与命中顺序一致。
- 继承绘图显隐开关：隐藏时文字不绘制、不命中，清除待放置和选择；切换周期不按“可见范围”过滤文字。文字不参与价格轴自动缩放。

普通页和历史页均接入对象列表、设置、显隐、清空和快捷键；归档只放开绘图，成交与账户等继续只读。会话切换、图表卸载或对象被刷新移除时，关闭相应编辑器、清除预览和排队帧；旧异步响应不能回填另一个会话。

## 4. 设置面板

### 4.1 布局与控件

新建和编辑共用 `TextSettingsDialog` 的草稿与保存逻辑；原地输入由 `TextInlineEditor` 提供，普通页与历史页也复用这两者。完整设置沿用趋势线的 `Dialog`、白色表面、Slate 边框、蓝色选中态、`max-w-md`、字段间距和底部操作布局，不照搬截图的字体、黑色按钮或页签风格。

```text
文字设置                                      ×
输入文字并设置外观。
──────────────────────────────────────────────
模板          [选择已保存模板              ▾] [删除]
文字颜色      [色块] #2962FF
字号          [18 px                       ▾]
字体样式      [B 粗体] [I 斜体]
文字内容
[多行输入框                                  ]
[                                            ]
0 / 2000 字符，最多 50 个手动行
□ 背景        [启用后显示颜色与不透明度]
□ 边框        [启用后显示颜色]
□ 文本换行    [启用后显示内容宽度]

确认后，此外观将作为下一次文字绘图的默认样式。
──────────────────────────────────────────────
[保存模板]                       [取消] [确认]
```

桌面字段标签列复用样式控件的 7rem 模式，窄屏上下排列；输入框和主要按钮保持 40px 高。复用 `StyleTemplateField`、`StyleColorField`、`StyleOpacityField`、`Select`、`Textarea` 和 `Button`。B/I 为独立切换按钮，使用 `aria-pressed`、中文名称及统一焦点环；不只依赖字形或颜色表达选择。

“保存模板”打开现有风格的独立名称弹窗，不在主表单常驻模板名称。切到名称弹窗时，`TextSettingsDialog` 组件保持挂载，局部文字、锚点、样式和预览均保留；名称弹窗取消或 Escape 只返回主设置，最终取消主设置才清除对象草稿。无“可见范围”页签，也不增加只有一个选项的“文字”页签。模板只在设置中管理，不放进绘图工具菜单。

### 4.2 参数与默认值

| 参数 | 默认值 | 规则 |
| --- | --- | --- |
| 文字内容 | 空；不作为默认样式保存 | 纯文本，最多 2000 UTF-16 单元、最多 50 个手动行，至少一个非空白字符 |
| 文字颜色 | `#2962FF` | 复用已有绘图蓝色；六位 HEX |
| 字号 | 18px | 枚举：12、14、16、18、20、24、28、32、36、48px |
| 粗体 / 斜体 | 均关闭 | 可组合，作用于整段文字 |
| 背景 | 关闭 | 启用时白色、不透明度 90%；颜色和 0～100% 不透明度可设置 |
| 边框 | 关闭 | 启用时使用绘图蓝色、1 CSS px 实线；本期不扩展线型和线宽 |
| 文本换行 | 关闭 | 关闭时仍保留 Enter 输入的手动换行；开启后自动折行 |
| 换行内容宽度 | 240px | 仅开启自动换行时展示，整数 120～800 CSS px，不包含两侧内边距 |
| 字体 / 行高 / 对齐 | 站点无衬线字体栈 / 字号的 1.4 倍 / 左对齐 | 固定，不新增选择项或外部字体依赖 |

开关关闭时保留对应颜色、透明度、宽度，重新启用可恢复。未勾选时收起附属控件，避免无法解释的禁用色块。字体颜色始终不透明，不会因关闭背景和边框而成为完全透明对象。

Enter 在内容框中换行，不提交表单；中文输入法确认不触发提交或关闭。非法内容或数值的错误紧邻字段，通过 `aria-describedby` 关联；错误时禁用确认。数值字段保留清空、编辑中的字符串状态，不能把暂时空值立即改成 0。提交期间显示加载、禁止重复确认与关闭，失败保留草稿。

弹窗内部滚动，最大高度 `calc(100dvh - 2rem)`，375px 下不产生页面横向滚动，底部操作可滚动到达。设置入口与对象窗口提供键盘编辑、选择和删除路径，Canvas 不承担唯一的信息入口。

### 4.3 模板与默认样式

模板只保存 `TextDrawingStyle`，不保存文字内容、锚点、会话或对象 ID。应用模板不会覆盖正在编辑的文字。名称最多 50 字符、每类最多 50 个，名称去空白并按现有规则匹配同名；覆盖同名模板的交互对齐现有共享设置，删除模板直接生效。保存模板只校验样式和名称，空白内容不妨碍保存样式模板。

保存、覆盖、删除模板立即更新模板偏好；之后取消对象编辑不撤销模板操作。这与现有 `LineSettingsDialog` 的模板生命周期一致，不为模板引入额外事务。对象确认成功才更新下一次默认样式，模板变更与默认样式更新分开处理。

文字样式模板和默认样式使用独立偏好键 `market-replay-text-preferences-v1`，由 `use-replay-preferences.ts` 统一读写。浏览器存储不可用时保留当前内存内的样式设置，并正常向后端保存对象。确认对象保存成功后才更新默认样式；取消或保存失败不更新。已有趋势线、斐波那契和矩形偏好保持独立。

## 5. 数据模型与接口

复用 [MarketDrawing](../../prisma/schema.prisma) 的 `type: String`、`geometry: String`、`style: String` 和会话索引，不新增数据库字段、Prisma 迁移或原始行情接口。

```ts
type TextGeometry = {
  anchor: DrawingAnchor; // timestamp、sourceSequence、price，复用现有规则
  text: string;
};

// 仅存在于新建编辑器内，允许内容为空；不传给对象存储接口。
type TextPlacementDraft = {
  anchor: DrawingAnchor;
  text: string;
  style: TextDrawingStyle;
};

type TextDrawingStyle = {
  color: string;
  fontSize: 12 | 14 | 16 | 18 | 20 | 24 | 28 | 32 | 36 | 48;
  bold: boolean;
  italic: boolean;
  backgroundEnabled: boolean;
  backgroundColor: string;
  backgroundOpacity: number; // 0..100，整数
  borderEnabled: boolean;
  borderColor: string;
  wrapEnabled: boolean;
  wrapWidth: number; // 120..800，整数，内容宽度
};

type TextDrawing = {
  id: string;
  datasetId: string;
  type: "TEXT";
  geometry: TextGeometry;
  style: TextDrawingStyle;
  createdAt: string;
  updatedAt: string;
};
```

文字内容与锚点共同存入该对象的 geometry JSON，是为了沿用现有存储信封；内容属于对象数据，不混入样式或模板。不伪造第二个锚点，也不把内容编码进 ID。

- `MarketDrawing` / `MarketDrawingStyle` 增加文字分支，新增 `DrawingGeometry = TrendLineGeometry | TextGeometry`。两点工具继续使用原类型，创建请求和预览使用带 `type` 的判别联合；拖动状态也区分单锚点与两点工具。创建输入由创建 schema 推导或显式定义相关联合，不能直接使用非分布式 `Omit<MarketDrawing, ...>` 而丢掉 type / geometry / style 的对应关系。
- `onPlaceText` 只交付锚点；编辑器用 `TextPlacementDraft` 保存空内容和编辑中状态，校验通过并确认后才构造完整 TEXT 创建输入。空白内容期间不把不合法草稿强转为 `MarketDrawing`，也不绘制虚假的已保存对象。
- POST 继续使用现有会话 drawings 集合接口，`{ type: "TEXT", geometry, style }`。文本必填，样式可取已定义完整默认值。
- PATCH 继续使用单对象接口，可同时更新完整的文字 geometry 和 style，保证一次编辑原子保存。事务先读取归属对象，再按该对象的 type 校验 geometry 和 style；禁止把文字 geometry 写给趋势线或反向写入。
- 拖动 PATCH 发送 `{ geometry: { anchor: nextAnchor, text: originalText } }`，不丢内容；内容修改保留原 anchor。位置、内容、样式完全未变时不提交。
- `serializeMarketDrawing` 按实际 type 解析对应 JSON。现有三类对象和偏好无需迁移；文字采用自己的默认值与严格校验，不放宽旧类型校验。
- 内容统一把 CRLF / CR 规范为 LF，再按相同规则在前后端校验长度和手动行数；保存前只用 trim 判断是否为空，实际保留前后空白和换行。粘贴 Tab 的显示按四个空格排版，内容本身保留 Tab；它在长度统计中占一个 UTF-16 单元。
- 使用 Canvas `fillText` 和受控 Textarea 处理文本；对象摘要也按纯文本输出，不解析 HTML、Markdown 或脚本。
- 复用会话作用域、`X-Replay-Projection`、归档绘图写入校验与纠错锁。DELETE / 清空保留既有会话隔离、失败恢复和并发新增保护。普通页和历史页均读取后端；不恢复浏览器绘图草稿。
- 客户端临时 ID、模板 ID 使用统一 [createUuid](../../lib/uuid.ts)，普通 HTTP 下也可工作。临时预览不写 localStorage。

更新含文字对象的版本后，旧应用不识别 `TEXT`；“无结构迁移”不代表旧客户端兼容新类型。发布时构建、重启并刷新客户端；若需回退，先遵循 [升级与回退指南](../operations/upgrade.md) 保留备份，不能静默丢弃文字记录或删除对象来规避解析错误。本轮只写设计，不执行部署或数据库操作。

## 6. 图表与性能设计

### 6.1 复用现有热路径

沿用 [ReplayChart](../../components/market-replay/replay-chart.tsx) 的按类型分组、共享 [DrawingTimelineLocator](../../lib/market-replay/drawing-timeline.ts)、rAF 合并和 ref 预览。单个图表只挂一个文字 primitive，无对象时不安排额外持续动画，不建立轮询或逐对象监听器。

新建内容和样式编辑在 `TextSettingsDialog` 的局部 state 中进行。通过图表级稳定的 `drawingApiRef` / `useImperativeHandle` 预览方法把当前文字草稿写入图表 ref，并加入现有 rAF 调度；不通过每次输入重建整个 `drawings` 数组来预览。持久化数组只在加载、乐观提交、服务端返回或回滚时变化。接口额外提供当前单一编辑锚点的位置订阅，由共享时间轴换算坐标；输入组件不读取图表业务状态。

原地编辑时只挂载一个共享 `Textarea`，通过 portal 放在图表交互容器内，沿用现有按钮与焦点样式。Canvas 不对当前编辑对象重复布局、绘制或命中；其余对象保持原有 Canvas 路径。编辑框靠近边缘时限制在价格区，限制高度并允许滚动，不改变持久化锚点；输入和面板尺寸变化才调整文本域高度。关闭时清理位置订阅、ResizeObserver、外部点击监听和预览，不建立持续帧循环。

文字编辑预览用对象 ID 替换对应持久化对象的显示版本，不额外叠画一份；新建预览单独保存。预览合并遵循顺序：持久化对象 → 编辑草稿 → 拖动位置，编辑期间不允许同时拖动。取消直接恢复持久化版本。

**新建的交接方式固定为“请求期间仅保留独立预览”。** 现有普通页创建函数和历史 hook 会先加入 `temporary-*` 乐观对象，文字创建不得直接照搬该显示步骤，否则半透明背景会叠画。文字分支复用现有请求锁、错误和提交逻辑，但 POST 返回成功前不向 `drawings` 集合追加临时文字；成功后只追加一次服务端对象，并在图表接收该版本的同一绘图帧清除新建预览、切换选中 ID。失败时保留一份编辑器草稿和预览，手动重试不新增另一份；不改变三类旧工具的乐观创建行为。编辑已有文字仍按对象 ID 覆盖乐观版本。

### 6.2 排版缓存与失效

排版模块与 React、Prisma 和行情数据解耦，注入文字测量函数，便于单测。缓存保存行文本、各行位置、行宽、行高和包含斜体字形外伸的包围盒，不缓存屏幕锚点。使用一个可复用测量 context，不创建逐对象或按文字全文尺寸扩张的 Canvas。

| 变化 | 重新定位 | 重新测量 / 换行 |
| --- | --- | --- |
| 平移、缩放、拖动、播放、窗口更换 | 是 | 否，命中现有排版缓存 |
| 选择、颜色、背景颜色/透明度、边框开关/颜色 | 按需 | 否 |
| 内容、字号、粗斜体、自动换行开关、启用时的宽度 | 当前对象 | 仅当前对象 |
| 字体实际加载完成 | 是 | 字体代次更新，相关缓存失效一次 |
| DPR 改变 | 是，重绘 | CSS 像素排版不因 DPR 单独失效 |

缓存键至少包含内容、字号、粗体、斜体、换行开关、有效换行宽度和字体代次。颜色、选择、锚点、视口范围和行情版本不进排版键；关闭换行时修改保留的宽度不触发重排。一个对象只保留当前排版版本，不把逐次输入的所有前缀永久保留。

缓存采用有界管理：最多 512 个对象布局、估算总量不超过 8 MiB，任一达到即按最近使用淘汰；估算包含文本、行片段和度量记录，所有附属测量缓存也必须有明确上限。对象删除时移除相关条目，会话切换和 detached 时清空缓存、字体监听与帧任务。超过容量的密集场景不承诺全量缓存命中，需在压力报告中说明淘汰和重排成本。

手动换行与自动折行分开处理，连续空格和空行保留；自动折行支持中文、长英文、数字和 emoji，不从 UTF-16 代理对中间拆分。优先使用可用的 `Intl.Segmenter`，缺失时提供字素分割回退，覆盖组合音符与常见 ZWJ emoji；不因这一能力引入 HTTPS 要求或新的编辑器依赖。

换行不能在每个候选字符上重新测量不断增长的全文前缀形成平方开销，应分段并复用度量，校正实际行宽。使用 `TextMetrics` 的字形边界或保守回退处理粗斜体，绘制和命中共用排版结果，避免字已画出但点不中。首版使用 Canvas 文字绘制及排版缓存，不引入 OffscreenCanvas、逐对象位图或无限尺寸的栅格缓存。

### 6.3 裁剪、命中与层级

- 使用共享时间轴将 anchor 换成逻辑序号，再调用 `logicalToCoordinate` / `priceToCoordinate`。屏幕坐标及文字尺寸以 CSS 像素计算，Canvas 目标负责设备像素比例；不改写保存锚点来“修正”缩放。
- 先进行保守的粗裁剪，再用完整文字包围盒判断是否与价格窗格相交。不能仅凭锚点在屏外就跳过：锚点在左侧或上方而文字仍可见时必须继续绘制和命中。
- 完全屏外且已知布局的对象跳过背景、边框、文字和命中。冷缓存中无法证明完全屏外的对象允许测量一次以判断边界，不能为追求零测量而错误隐藏文字。
- 所有绘制 clip 到价格窗格，不画到坐标轴、成交量区域或弹窗。长文字只遍历与窗格纵向相交的行，不对每个屏外行调用 `fillText`；不截断或省略保存的内容。
- 正文、可选背景和持久化边框均在 `top` view 的 `drawBackground` 阶段绘制，位于 K 线和矩形填充之上、现有线条与编辑句柄之下；文字选中框和锚点在自身 `draw` 阶段绘制。依照 [primitive 层级接口](https://tradingview.github.io/lightweight-charts/docs/plugins/series-primitives) 安排，命中规则与第 3.2 节一致。
- 库内 `hitTest()` 的正文/持久化边框命中返回 `isBackground: true`，锚点命中返回前景标记；只有实际控制点获得句柄优先级，临时选中框不独立抢占正文命中。`ReplayChart.hitDrawingAt` 按第 3.2 节增加明确的类别优先级，再比较同类距离和顺序，不能只用正文框的零距离与现有线条比较。库内悬停光标与自定义 pointerdown 必须选择同一类对象。
- 命中只读取已投影矩形与可见性，不重新测量、不重新格式化时间、不扫描全部行情。同类型由前到后查找候选；不新建复杂空间索引，先用 500 个混合对象压测确认是否需要。
- 不实现扩大价格范围的 `autoscaleInfo`，不向 series 增加虚拟行情点，不为了显示文字读取完整历史。

### 6.4 资源边界与性能验收

2000 字符、50 个手动行、最大字号和最大换行宽度都在前后端校验。实际自动行数受字符数约束；即使很长也只画可见行。不能把不合法输入截掉后静默保存，也不能降低其他绘图的资源限制来掩盖文字性能。

新增合成数据基准 `benchmark:text-drawings`（计划命令），参考现有 [矩形基准](../../scripts/benchmark-rectangle-drawings.ts)，不读业务库、不依赖网络。分别测量纯文字与四类混合对象，在 50 / 200 / 500 个对象、短文本、多行、2000 字符长段落、换行、部分屏外等条件下记录冷启动、热投影/命中、拖动、输入单对象重排、窗口/周期切换、缓存占用及淘汰次数。

实施必须验证的机制：

1. 在缓存未淘汰且字体未变化时，热平移/缩放/拖动/选择和颜色变化新增 `measureText` 调用数为 0；修改一段内容只使该对象失效。
2. 同一时间轴配置下重复投影新增时区换算数为 0；沿用共享日历，不按文字重复构建。
3. 每帧最多处理一次最新指针预览、一次合并绘图同步；拖动过程不写库，松开后有变化才一次 PATCH。编辑文字/样式不发请求，确认才一次 POST 或 PATCH；不自动重试写请求。
4. 全屏外的热缓存对象没有文字/背景绘制；隐藏绘图时没有文字绘制或命中；循环新建编辑删除后缓存不持续增长。

性能预算作为实施目标，尚未实测：在同一机器、同一合成数据下，200 个混合对象的热更新（坐标、缓存读取和命中，不含浏览器 Canvas）P95 目标不超过 4ms。真实浏览器另用 50 / 200 个对象连续平移、缩放、拖动和播放采样 30 秒，目标是绘图相关交互帧 P95 在 16.7ms 内、没有可归因于文字功能的 >50ms 长任务；2000 字符的一次局部重排目标在 16ms 内。记录设备、构建、DPR、可见行数和测量方法，达不到就定位、优化并写明实际边界，不能把目标当验收事实。

500 个对象作为压力场景，单独记录帧间隔、长任务、缓存失效和内存，不承诺稳定 60 FPS。既有文档已记录 500 个混合对象的停顿，必须保留无文字的对照组，区分文字新增成本与行情推进、其他标签、浏览器环境成本；投影微测不能代替整页测试。

## 8. 实施顺序与验收清单

1. **数据与校验先行**：实现 TEXT 类型和 schema、序列化、按实际类型校验更新；先用隔离 SQLite 验证创建、编辑、刷新与跨会话隔离，再接入 UI。
2. **排版与 primitive**：文字度量注入、缓存失效与上限、裁剪、命中、选中态和单锚点拖动；先跑合成基准，避免功能全部完成后才发现热路径问题。
3. **公共设置与两类页面接线**：局部草稿预览、模板、菜单、Shift + T、对象窗口、显隐和取消；避免在两个客户端复制表单或排版逻辑。
4. **回归与浏览器检查**：按下表验证，记录性能事实和 UI 检查结果，再补充使用文档。

| 范围 | 必验场景 |
| --- | --- |
| 快捷键 | Shift + T、大小写/物理键回退、组合修饰拒绝、repeat、中文组字、输入框和可见弹窗屏蔽，Alt + T/F 与 Shift + R 无回归 |
| 新建与编辑 | 一次放置、空白拒绝、多行/空格/粘贴、取消无记录、内容与样式一起保存、失败不丢输入、重复确认阻止、延迟 POST 和失败重试只有一个文字框、取消还原、无变化不提交 |
