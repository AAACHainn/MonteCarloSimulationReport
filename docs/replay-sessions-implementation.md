# 回放多会话与实盘重演实施记录

## 已确定的产品规则

- 一份行情共享多个独立回放会话，模式创建后固定为训练或实盘重演。
- 实盘重演沿用现有撮合结果，不加入真实成交覆盖或券商导入。
- 实盘会话长期续用，按数据集交易日查看；训练与实盘统计隔离。
- 训练禁止删除成交和状态回退，包括归档后；重新开始归档旧会话并创建新会话。
- 删除以净持仓从空仓到再次空仓的完整周期为单位；持续反手仍属于同一周期。
- 回退到目标源 K 线撮合结束、用户操作前，撤销后续操作并恢复完整账户与统计。
- 纠错后台分块重建，先预览后确认，确认时原子切换结果版本。失败或取消保留原状态。
- 旧会话迁移为训练，保留已有记录，不补造历史；新实盘会话支持完整纠错。
- 保留现有组件与撮合规则。UI 验收使用实际桌面窗口，按用户要求不做固定宽度矩阵或新增窄屏适配。

## 技术衔接说明

- 现有数据集级交易 API 通过 `replaySessionId` 查询参数显式绑定会话（原 `sessionId` 参数仍表示日志会话，不混用）；同时提供 `/api/replay-sessions/:id/...` 会话接口。
- 交易写请求要求 `X-Replay-Projection`；旧版本写请求被拒绝，备注编辑允许同步同逻辑记录的多个版本。
- 新增 SQL 迁移依次为 `20261013120000`（会话）、`20261013130000`（周期/因果/幂等）、`20261013140000`（旧记录存储 ID 归属）、`20261013150000`（保留复盘数据库约束）。初始化兜底已同步；首个迁移在关闭外键后用事务执行，再重新开启外键。
- `corepack pnpm` 在当前环境不会自动找到项目 `.bin`，验证命令需临时将 `node_modules/.bin` 放到 PATH 前；Prisma CLI 可通过 `node node_modules/prisma/build/index.js ...` 执行。
- esbuild/Vitest/Prisma schema engine 启动在沙箱中会出现 `spawn EPERM`，已通过工具自动审核允许本地测试/生成。不是需要用户重复确认的阻碍。
