# 回放多会话与实盘重演实施记录

## 已确定的产品规则

- 一份行情共享多个独立回放会话，模式创建后固定为训练或实盘重演。
- 实盘重演沿用现有撮合结果，不加入真实成交覆盖或券商导入。
- 实盘会话长期续用，按数据集交易日查看；训练与实盘统计隔离。
- 训练禁止删除成交和状态回退，包括归档后；重新开始归档旧会话并创建新会话。
- 删除以净持仓从空仓到再次空仓的完整周期为单位；持续反手仍属于同一周期。
- 回退到目标源 K 线撮合结束、用户操作前，撤销后续操作并恢复完整账户与统计。
- 纠错后台分块重建，先预览后确认，确认时原子替换当前记录并删除旧结果。失败或取消保留原状态并清理预览。
- 旧会话迁移为训练，保留已有记录，不补造历史；新实盘会话支持完整纠错。
- 保留现有组件与撮合规则。UI 验收使用实际桌面窗口，按用户要求不做固定宽度矩阵或新增窄屏适配。
