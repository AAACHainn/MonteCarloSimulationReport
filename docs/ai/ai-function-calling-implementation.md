五个工具为 `list_trade_records`、`get_trade_record`、`get_review_template`、`get_chart_context`、`get_session_statistics`。它们只读取绑定快照，不接受 SQL、Prisma 查询、任意 URL 或文件路径。列表摘要、统计分组和目录不计作逐笔正文/图片已读。未知计划风险不会使用 tick 或实际不利波动兜底。

已平仓 lot 可通过与撮合器共用的稳定身份规则关联入场/退出成交和可靠订单；无法证明归属的周期事件仍不返回给单笔工具。共用身份生成器保持原 ID 字符串不变，不新增完整持仓归属或费用分配能力。

工具执行记录与最终消息分开。成功输出只允许已送达模型的来源；可采用复盘还须读取事实和模板/草稿状态，未附草稿且已有正文时须读取正文。采用仅填编辑器，正式保存由用户完成；冲突保留现有内容。通用兼容策略不发送未经适配的 strict/并行参数或思考续传字段；DeepSeek 策略保留实际返回字段。旧消息不伪造完整协议。

普通工具运行默认最多 6 次模型请求，最后一轮关闭新工具；默认最多 12 次工具调用，每轮最多 4 个并串行。参数 16 KiB、单结果 32 KiB、默认累计结果 256 KiB、普通累计输入 240,000 字符，计入重放、工具定义与图片估算。协议正文不含图片 Base64。每次请求图片总量最多 12 MiB。未知用量保留 null，失败调用也占额度，不自动重试未知计费请求。后续需求已加入全局与聊天临时上限及实际用量展示，允许范围集中在 `lib/ai/limits.ts`，详见[使用说明](ai-assistant.md#限制存储和部署)；资源保护与收束规则继续适用。

图表请求默认可见柱预算合计 120、硬上限 200；目前每页保守最多合计 80 根以给 JSON 元数据留空间，再受 32 KiB 限制，截图与实际页对应。窗口只输出完整柱，缺历史/形成柱/未准备图片明确标注。背景范围规划使用时间索引，不先聚合全部候选周期；实际读取仍复用公共聚合器，并限制扫描与查询。图表偏好冻结 EMA、Bar Count、时区/时段、颜色及渲染版本；指标预热最多 1,000 根。图片上传关联与字节 hash 不等于服务端逐像素验证。

完整会话不会把自由循环套进每一批。所有冻结行（含无复盘和无图记录）进入覆盖台账；批次保留实际输入 hash 和来源回执，压缩不授予未读来源。最终核对与程序批次默认共享 750 次、5,000,000 字符上限，预留最终核对额度。快速模式明确不代表审阅全部图。未完成不创建完整报告；已上传图片及现有 Node worker 继续支持关闭窗口后的分析。

界面复用现有 Select、Input、CheckboxField、Dialog；新增固定文案集中到 `copy`。资料读取记录采用原生 details/summary 默认折叠，与思考分开，不展示参数 JSON 或费用。使用隔离升级副本及无头 Chrome 检查 375/1280/1440/1920px 的设置、读取记录与周期选择，横向溢出检查通过，键盘展开/收起与 Escape 通过；没有改动无关旧界面。未触发真实端点的拉取、连接测试或聊天。

数据库使用 String 保存 JSON。新增迁移与 `scripts/init-sqlite.mjs` 同步；实际库无 Prisma 迁移历史，沿升级指南的初始化路径先备份、副本演练，再升级。备份包含 SQLite 一致性快照、环境和现有存储，位于被 Git 忽略的 `tmp/ai-function-calling/backup-20261016`。不提交数据库、环境、截图、日志或构建产物。

升级演练及正式库升级均逐表核对原有 45 张表的原字段内容摘要，没有变化；SQLite integrity_check 为 ok，foreign_key_check 无记录。另在全新隔离库通过 38 份 Prisma 迁移链，覆盖两种安装路径。原主密钥及环境文件保持原值。

同问题、同冻结范围的本地协议夹具对照中，两种模式均通过草稿结构与来源校验：固定资料模式 1 次请求、估算输入 1,440 字符，工具模式 2 次请求、14,128 字符；某轮样本耗时分别 20/48ms。此数字仅是内存模拟协议的局部测量，不代表供应商延迟、费用或质量；模拟最终轮返回的 10/5 Token 不是实际计费，工具中间轮未报告的用量保留 null。独立 Node worker 另用本地 HTTP 模型和已上传图片完成完整会话，证明不依赖浏览器继续存在。
