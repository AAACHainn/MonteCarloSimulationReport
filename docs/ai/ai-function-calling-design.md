# AI Function Calling：历史设计摘要

日期：2026-10-16。本文压缩首版设计中的稳定边界与统计口径，作为历史决策记录。A—C 首版实现及当时验证见[实施记录](ai-function-calling-implementation.md)；当前聊天、配置和限制以[AI 机器人说明](ai-assistant.md)为准，图表图片以[AI 图表图片工具](ai-chart-images.md)为准。这里的历史设计或验证不代表本轮重新验证。

## 协议与安全边界

- 工具由应用注册，只接受领域参数；不接受 SQL、Prisma 查询、任意路径或 URL。服务端仍校验长度、枚举、范围、分页与时间，不能依赖模型的 strict/schema 输出代替业务校验。
- 供应商的“OpenAI compatible”标签不保证相同能力。适配器只发送经过协议适配的字段；DeepSeek 等协议的工具轮次按服务真实返回内容续传，不伪造模型调用或隐藏思考内容。
- 每次运行固定会话、projection、数据截止点、工具契约版本、端点与预算。来源回执只证明模型实际收到的证据；摘要、目录或压缩文本不能冒充读取了逐笔正文或图片。
- 交易事实、图表、模板与统计均为只读。复盘草稿通过已读来源和原文冲突检查后仅可写入编辑器，正式保存由用户操作。

## 工具边界

首版领域工具按职责划分为：

| 能力 | 契约边界 |
| --- | --- |
| `list_trade_records` | 在冻结范围内筛选和定位 FIFO 日志行；分页结果提供稳定引用。日志行不是完整持仓交易。 |
| `get_trade_record` | 按引用及 section 读取事实、已保存复盘、历史检查快照和可靠归属的执行事件；缺失或无法归属的信息明确标出。 |
| `get_review_template` | 读取本次明确选择的模板与未保存草稿。显式空草稿仍是有效输入；草稿、已保存复盘和模板保留各自来源。 |
| 图表能力 | 早期 `get_chart_context` 设计已由[图片工具文档](ai-chart-images.md)取代。当前按冻结窗口取得真实图片，不把逐根行情发给模型；明确要求时可请求多周期。 |
| `get_session_statistics` | 只对冻结的完整会话提供固定统计视图；单笔 scope 不注册该能力。 |

计划中移除通用 `get_scope_context` 与 `get_source_evidence`：程序直接提供必要的范围清单，具体事实由原领域工具重读，避免通用来源引用成为越权取数入口。图表工具实现和自动资料选择后来有调整，分别以当前 AI 文档为准。

## 统计单位与口径

总体视图以完整、已结束的 `PaperTrade` 为统计单位：净盈亏为 `grossPnl - fees`，费用只扣一次；胜率按净盈亏正负分类，平衡交易仍在分母；计划风险 R 只纳入 `plannedRisk > 0` 且可验证的样本。开放持仓不混入已结束交易，缺失风险不得用零值、tick 或实际不利波动补造。

Setup/方向视图以 FIFO 日志行为单位，按日志价差分类且未扣费。它不能被称为 Setup 的扣费净收益；一笔完整持仓可能对应多行，不能把行数当作完整交易数，也不能按行数或价差分摊持仓费用。缺少可靠映射时，净额分组与“最有利 Setup”结论不可计算。

使用稳定 Setup ID 分组；胜负分类需与日志容差一致。同名 Setup 不合并，缺 Setup、缺复盘和缺检查的记录不能从覆盖统计中静默消失。统计结果需携带币种、统计单位、覆盖范围、缺失项和分页完整性。

## 预算、覆盖与后续阶段

早期设计建议普通工具问答限制模型轮次与工具调用，并为最终收束预留预算；具体可配置限制以当前 [AI 机器人说明](ai-assistant.md) 为准。会话报告需冻结全量交易清单并维护覆盖账本，预算不足时明确报告未覆盖范围，不能把部分样本说成完整会话总结。

A—C 阶段的协议闭环、交易读取、模板、图表及首版统计以历史实施记录为证据。D 阶段保留为未完成的统计增强：冻结完整持仓事实，可靠映射到 FIFO 行及 Setup，处理部分平仓、反向、混合 Setup 和费用归属，并以独立纯函数与真实账本对账。跨会话、知识库、写工具及额外协议也不应因增加一个工具名而被视为已经实现。
