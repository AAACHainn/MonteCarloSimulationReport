## 实现与保护

新增 `UserWallet`、`UserWalletEntry`、`UserWalletAllocation`，以整数分保存金额。交易账户原有浮点计算保持，结算边界统一四舍五入到分。新增迁移 `20261026140000_user_wallet` 与初始化脚本复用相同 SQL，初始发放幂等。

已有用户的期初钱包与初始流水时间取原用户创建时间，作为一次性期初记录，不代表恢复了历史发放。这样副本演练与实际升级得到相同数据，避免使用各自执行时间导致完整指纹不同。新建用户仍以实际创建时间记账。

资金、账户、轮次、出金、成长及删除在同一 SQLite 写事务完成。来源唯一键防重复记账，余额版本校验防冲突；失败保留原会话和原余额。删除前读取金额预览，提交时重新校验版本、条件和金额。前端提示不足，服务端仍负责最终检查。
