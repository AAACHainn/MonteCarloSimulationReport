- 在档案经验区右上角显示轻量“经验与境界规则”按钮，默认打开“获取经验”；原进度、剩余经验及下一步说明保留。
- 境界轨迹下增加“查看晋升门槛”，直接打开同一弹窗的“境界晋升”。头像弹窗不增加入口。
- 获取经验页列出完整持仓周期、首次逐笔复盘、每轮考核通过、每轮首次出金的奖励与限制，说明归属/资格、重复奖励、AI 草稿采用、历史与删除口径。
- 境界晋升页展示凡人、炼气十二层及筑基一层，共 14 行；分别列累计经验要求与相邻门槛差额。当前行依据实际 realm/layer 高亮，经验超额但未突破仍显示炼气十二层；成长资料待确认时不虚构高亮。
- 筑基说明明确累计经验门槛、六项成果条件及手动突破要求，完整缺口仍由原“筑基条件”区域展示。后续境界不设置虚构门槛。

奖励直接读取 GROWTH_XP，门槛和差额直接读取 QI_THRESHOLDS / FOUNDATION_REQUIREMENTS，无重复写死数值。新固定文案统一在 copy.userGrowth.guide。复用 Dialog、Button、Table、Badge；最大宽度 max-w-2xl，内容内部滚动，不新增 UI 规范例外。

页签支持点击、左右键循环、Home/End；选中页签提供初始焦点，Tab 可访问表格说明，Escape 关闭并返回入口焦点。
